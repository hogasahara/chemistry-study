# 先生のプリント登録簿

ドリルの元になる「先生独自のプリント」を1枚(1回分)ずつ登録する。**このフォルダはサイトに公開されない**(_config.yml で除外)が、リポジトリには残るので次のルールを守る。

- プリントの原本(画像・PDF)や本文の丸写しは置かない。**範囲・用語・要点・例題の型**だけをメモする
- 学校名・先生の名前など、個人が特定できる情報は書かない
- 授業で扱ったかどうか(復習用か)と、テスト範囲かどうかを分けて書く

## 登録のしかた

1. `prints/<プリントID>.md` を作る。IDは `p01`, `p02` … の連番(先生の通し番号があればそれに合わせる: `no03` など)
2. 下のテンプレートを埋める
3. 下の「一覧」に1行追加する
4. このプリントから作ったドリルの drill.json の `source.print` に `prints/<プリントID>.md` を書く

## テンプレート

```markdown
# プリント <番号>: <タイトル>

- 受け取った日: YYYY-MM-DD
- 単元: (例: 物質量)
- 授業で扱った: はい / まだ
- テスト範囲: はい / いいえ / 未確定

## 範囲(見出し)

## 出てきた用語・化学式(→ drill.json の terms 候補)

## 要点・公式

## 例題・練習問題の型(→ ドリルの設問の型。数値はドリル側で変える)

## 表記のクセ(用語の書き方・原子量の値・有効数字など)
```
