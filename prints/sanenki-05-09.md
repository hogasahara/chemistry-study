## 範囲(見出し)

- 5: ② 指示薬と pH の測定(P142)— フェノールフタレイン(PP)pH 8.0〜9.8 無色→赤(塩基性側で変色)、メチルオレンジ(MO)pH 3.1〜4.4 赤→黄(酸性側で変色)。③ 中和と塩(P143)1 中和 — 酸 + 塩基 → 水 + 塩。H<sup>+</sup> と OH<sup>−</sup> の個数(mol)が等しいとき完全に中和、酸・塩基の強弱と無関係(電離度を考える必要なし)。考えてみよう: 酢酸100個(α = 0.01)に必要な NaOH の個数。※2 NH<sub>3</sub> の中和は水を生じない(HCl + NH<sub>3</sub> → NH<sub>4</sub>Cl)
- 6: 例題 (1) 中和の化学反応式(酢酸+KOH、リン酸+Ca(OH)<sub>2</sub>、シュウ酸+NaOH、硝酸+Cu(OH)<sub>2</sub>、硫酸+アンモニア)(2) 中和に必要な物質量(電離度はひっかけ)、塩酸と NaOH の混合溶液の水素イオン濃度
- 7: 2 塩とその種類(P144)— 酸の陰イオン + 塩基の陽イオンのイオン結合。H<sub>2</sub>SO<sub>4</sub> + 2NaOH → Na<sub>2</sub>SO<sub>4</sub>、H<sub>2</sub>SO<sub>4</sub> + NaOH → NaHSO<sub>4</sub>。正塩・酸性塩・塩基性塩(組成式で分類。液性とは無関係)。例題: 5つの塩の分類
- 8: 塩の水溶液の液性(P144)— 正塩: もとの酸・塩基の強い方の性質(強+強 → 中性、弱酸+強塩基 → 塩基性、強酸+弱塩基 → 酸性)。酸性塩: NaHSO<sub>4</sub> は電離で酸性、NaHCO<sub>3</sub> は加水分解で塩基性
