## 範囲(見出し)

- 1: ① 酸化と還元 — 定義の表(酸素を受け取る/失う、水素を失う/受け取る、電子を失う/受け取る)。例: CuO + H<sub>2</sub> → Cu + H<sub>2</sub>O、2H<sub>2</sub>S + O<sub>2</sub> → 2S + 2H<sub>2</sub>O、2Mg + O<sub>2</sub> → 2MgO。酸化と還元は必ず同時に起こる。O と結合する = 電子を失う、H と結合する = 電子を受け取る(電気陰性度で説明)
- 2: ③ 原子の酸化数 — ルール ① 単体は 0 ② 化合物中の H は +1、O は −2、総和は 0(例: NH<sub>3</sub>, SO<sub>2</sub>, HClO)。例外: 過酸化水素の O は −1、陽性元素の水素化合物(NaH, CaH<sub>2</sub>)の H は −1 ③ 単原子イオンは電荷に等しい ④ 多原子イオンは総和が電荷(NO<sub>3</sub><sup>−</sup>, SO<sub>4</sub><sup>2−</sup>)⑤ アルカリ金属 +1、2族 +2
- 3: 酸化数の計算(13問程度)、酸化数の変化(増加 → 酸化された、減少 → 還元された)。練習1: 下線部の原子が酸化・還元・いずれでもないか(8問)。練習2: 酸化された原子・還元された原子(5問)

## 表記のクセ

- 「酸化された」「還元された」と受け身で書く。電子は e<sup>−</sup>
