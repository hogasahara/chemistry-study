## 範囲(見出し)

- 10: ③ 塩の生成と反応(P135, 147)— 金属の酸化物 = 塩基性酸化物(Na<sub>2</sub>O, CaO, CuO)、非金属の酸化物 = 酸性酸化物(CO<sub>2</sub>, SO<sub>3</sub>)、オキソ酸。塩の生成7パターン(酸+塩基 / 酸+塩基性酸化物 / 酸+金属 / 酸性酸化物+塩基 / 酸性酸化物+塩基性酸化物 / 非金属+塩基 / 非金属+金属)
- 11: 塩の反応(P145, 146)— ① 弱酸の遊離・弱塩基の遊離 ② 揮発性の酸の遊離(NaCl + H<sub>2</sub>SO<sub>4</sub> → HCl + NaHSO<sub>4</sub>、加熱)③ 塩の加水分解(CH<sub>3</sub>COO<sup>−</sup> + H<sub>2</sub>O ⇄ CH<sub>3</sub>COOH + OH<sup>−</sup>)。例題: 2物質の反応式/反応しない(×)、加水分解で弱酸性を示す塩
- 12: ④ 中和滴定(P148)1 中和における量的関係 — H<sup>+</sup> の mol = OH<sup>−</sup> の mol、C×V/1000×a = C'×V'/1000×b。例題: 硫酸で NaOH の濃度 / シュウ酸(電離度は無関係)/ pH と電離度から酢酸の濃度を出して中和量
- 13: 2 中和滴定の操作 — ホールピペット・ビュレット・コニカルビーカー・メスフラスコ、指示薬(フェノールフタレイン・メチルオレンジ)、共洗い(ホールピペット・ビュレット)、コニカルビーカーとメスフラスコは純水でぬれたままでよい、目盛りのある器具は加熱乾燥しない
- 14: 3 中和滴定曲線(P152)— 強酸+強塩基(両方の指示薬OK)/ 弱酸+強塩基(中和点が塩基性側 → フェノールフタレインのみ)/ 強酸+弱塩基(酸性側 → メチルオレンジのみ)/ 弱酸+弱塩基(pHジャンプが見られず判定できない)。※指示薬は pH ジャンプ内に変色域があれば使える

## 要点・公式

- 酸の mol × 価数 = 塩基の mol × 価数(電離度は関係しない)
- 塩の液性は「もとの酸・塩基の強い方」: 弱酸+強塩基の塩 → 塩基性、強酸+弱塩基の塩 → 酸性
- NaHSO<sub>4</sub> は加水分解ではなく HSO<sub>4</sub><sup>−</sup> の電離で酸性(プリント例題のひっかけ)

## 表記のクセ

- 反応式の弱酸・弱塩基に「弱酸」「弱塩基」と注記、遊離は「追い出される」と表現
- 可逆反応は ⇄、加水分解の矢印に「加水分解」と書く
