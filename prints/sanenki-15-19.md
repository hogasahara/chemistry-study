## 範囲(見出し)

- 15: ④ 逆滴定 — 気体の試料(NH<sub>3</sub>、CO<sub>2</sub> など)を中和滴定で定量する場合。NH<sub>3</sub> を過剰の H<sub>2</sub>SO<sub>4</sub> に吸収 → 残った H<sub>2</sub>SO<sub>4</sub> を NaOH で滴定。例題(教科書P146)
- 16: 練習1 — 濃度不明の塩酸に NaOH を加えすぎ(中和点を超えた)→ 硫酸で中和し直して塩酸の濃度を求める
- 17: 練習2 — (NH<sub>4</sub>)<sub>2</sub>SO<sub>4</sub> と CaSO<sub>4</sub> の混合物 + 濃い NaOH → 気体A(NH<sub>3</sub>)を硫酸に吸収 → NaOH で逆滴定。弱塩基の遊離の選択問題、質量%の計算
- 18: 二段階滴定(Na<sub>2</sub>CO<sub>3</sub> の滴定)P154 — 中和点が2か所。フェノールフタレイン(第1)とメチルオレンジ(第2)。例題: 濃度 x の Na<sub>2</sub>CO<sub>3</sub> を塩酸で滴定、y mL で第1中和点、合計 30 mL
- 19: 混合塩基(NaOH + Na<sub>2</sub>CO<sub>3</sub>)の滴定(ワルダー法)P155 — 第1中和点までの量 a、第1→第2 の量 b。Na<sub>2</sub>CO<sub>3</sub> = b から、NaOH = a − b から求める

## 出てきた用語・化学式

逆滴定 / 酸の H<sup>+</sup> の総モル数 = 塩基の OH<sup>−</sup> の総モル数 / メチルレッド / 弱塩基の遊離 / 硫酸アンモニウム (NH<sub>4</sub>)<sub>2</sub>SO<sub>4</sub>(式量132)/ 二段階滴定 / 第1中和点・第2中和点 / フェノールフタレイン・メチルオレンジの変色域 / 炭酸水素ナトリウム NaHCO<sub>3</sub> / ワルダー法 / CO<sub>3</sub><sup>2−</sup> は弱酸由来の2価の陰イオンなので H<sup>+</sup> を受け取る力が大きい

## 要点・公式

- 逆滴定の関係式: 硫酸 A mol、NaOH B mol、NH<sub>3</sub> Z mol → **A×2 = B×1 + Z×1**
- 二段階滴定の反応
  - 第1中和点まで: CO<sub>3</sub><sup>2−</sup> + H<sup>+</sup> → HCO<sub>3</sub><sup>−</sup>(Na<sub>2</sub>CO<sub>3</sub> + HCl → NaCl + NaHCO<sub>3</sub>、塩基性)
  - 第2中和点まで: HCO<sub>3</sub><sup>−</sup> + H<sup>+</sup> → H<sub>2</sub>O + CO<sub>2</sub>(酸性)
  - ①の反応が終わってから②が始まる。**①と②で使われる酸の量は等しい**
- 混合塩基: 第1段階で NaOH の中和と Na<sub>2</sub>CO<sub>3</sub> → NaHCO<sub>3</sub> が起こる。第2段階は NaHCO<sub>3</sub> のみ
- 空気中の CO<sub>2</sub> で NaOH の一部が Na<sub>2</sub>CO<sub>3</sub> になる(2NaOH + CO<sub>2</sub> → Na<sub>2</sub>CO<sub>3</sub> + H<sub>2</sub>O)

## 例題・練習問題の型

- 逆滴定で吸収させたアンモニアの物質量(硫酸の価数2に注意)
- 加えすぎた NaOH を硫酸で戻す → 元の塩酸の濃度
- 混合物中の (NH<sub>4</sub>)<sub>2</sub>SO<sub>4</sub> の質量%(NH<sub>3</sub> 2 mol ↔ 塩 1 mol)
- 二段階滴定: 指示薬の色の変化(「赤色→青色」のように答える)、化学反応式、x・y の値
- 混合塩基: NaOH と Na<sub>2</sub>CO<sub>3</sub> の物質量をそれぞれ求める

## 表記のクセ

- 濃度は mol/L、体積は mL(有効数字3桁の問題が多い: 0.0500 mol/L、20.0 mL)
- 「総モル数」「物質量」の両方の言い方を使う
- 化学式の量は「式量」表記(例: (NH<sub>4</sub>)<sub>2</sub>SO<sub>4</sub> = 132)
