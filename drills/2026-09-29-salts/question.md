# 確認ドリル #3 — 塩の生成と反応

分野: 酸と塩基 ・ 出典: プリント 酸塩基10〜11 ・ 目安 12分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 塩基性酸化物 | 金属の酸化物。水に溶けて塩基性を示し、酸と反応して塩を生じる(Na<sub>2</sub>O, CaO, CuO など) |
| 酸性酸化物 | 非金属の酸化物。水に溶けて酸性を示し、塩基と反応して塩を生じる(CO<sub>2</sub>, SO<sub>3</sub> など) |
| オキソ酸 | O 原子を含む酸(H<sub>2</sub>CO<sub>3</sub>, H<sub>2</sub>SO<sub>4</sub> など) |
| 弱酸の遊離 | 弱酸の塩 + 強酸 → 強酸の塩 + 弱酸 |
| 揮発性の酸の遊離 | 揮発性の酸の塩 + 不揮発性の酸(加熱)→ 不揮発性の酸の塩 + 揮発性の酸 |
| 塩の加水分解 | 弱酸・弱塩基の塩から生じたイオンの一部が水と反応し、電離前の形にもどること |
| CH<sub>3</sub>COONa | 酢酸ナトリウム(弱酸+強塩基の塩。水溶液は塩基性) |
| NH<sub>4</sub>Cl | 塩化アンモニウム(強酸+弱塩基の塩。水溶液は酸性) |

## 設問

所要時間を測ってから始める。

**Q1.** CO<sub>2</sub> は水に溶けて酸性を示す、酸性酸化物である。

正 / 誤

**Q2.** CaO は水に溶けると酸性を示すので、酸性酸化物である。

正 / 誤

**Q3.** 【用語】 次のうち、塩基性酸化物はどれか。

- (a) SO<sub>3</sub>
- (b) CO<sub>2</sub>
- (c) Na<sub>2</sub>O
- (d) P<sub>4</sub>O<sub>10</sub>

**Q4.** 【反応式】 SO<sub>3</sub> + 2NaOH → 【 ア 】 + H<sub>2</sub>O のアに入る物質はどれか。

- (a) Na<sub>2</sub>SO<sub>3</sub>
- (b) Na<sub>2</sub>SO<sub>4</sub>
- (c) NaHSO<sub>4</sub>
- (d) Na<sub>2</sub>O

**Q5.** 【用語】 次の2つの物質を反応させたとき、反応が起こらない組み合わせはどれか。

- (a) CH<sub>3</sub>COONa と HCl
- (b) NH<sub>4</sub>Cl と NaOH
- (c) Na<sub>2</sub>CO<sub>3</sub> と HCl
- (d) KCl と CH<sub>3</sub>COOH

**Q6.** 【用語】 塩化ナトリウムに濃硫酸を加えて加熱すると発生する気体はどれか。

- (a) Cl<sub>2</sub>
- (b) HCl
- (c) H<sub>2</sub>
- (d) SO<sub>2</sub>

**Q7.** 【用語】 硫化鉄(II) FeS に塩酸を加えると発生する気体はどれか。

- (a) H<sub>2</sub>
- (b) SO<sub>2</sub>
- (c) H<sub>2</sub>S
- (d) Cl<sub>2</sub>

**Q8.** 【用語】 次の塩の水溶液のうち、塩基性を示すものはどれか。

- (a) CH<sub>3</sub>COONa
- (b) NH<sub>4</sub>Cl
- (c) NaCl
- (d) NaHSO<sub>4</sub>

**Q9.** 【用語】 次の塩の水溶液のうち、塩の加水分解によって弱い酸性を示すものはどれか。

- (a) KNO<sub>3</sub>
- (b) NaHSO<sub>4</sub>
- (c) NH<sub>4</sub>NO<sub>3</sub>
- (d) K<sub>2</sub>CO<sub>3</sub>

**Q10.** 塩は中和反応だけでなく、金属と酸の反応(例: Zn + 2HCl)などでも生じる。

正 / 誤
