## 解説

**Q1.** CO<sub>2</sub> + H<sub>2</sub>O → H<sub>2</sub>CO<sub>3</sub>(炭酸)。非金属の酸化物 → 酸性酸化物。

**Q2.** Ca は金属 → CaO は塩基性酸化物。CaO + H<sub>2</sub>O → Ca(OH)<sub>2</sub>(塩基)。定石: 金属の酸化物 = 塩基性、非金属の酸化物 = 酸性。

**Q3.** Na は金属なので Na<sub>2</sub>O は塩基性酸化物(水と反応して NaOH になる)。S・C・P は非金属。

ひっかけ: (a) 金属・非金属の取り違え / (b) 金属・非金属の取り違え / (d) 金属・非金属の取り違え

**Q4.** SO<sub>3</sub> は水と反応すると H<sub>2</sub>SO<sub>4</sub> になる酸性酸化物。NaOH 2 mol と中和して Na<sub>2</sub>SO<sub>4</sub>。定石: 酸性酸化物は「水を足した酸」に直して考える。

ひっかけ: (a) 酸化物と塩の対応の誤り / (c) 係数の誤り / (d) 生成物の誤り

**Q5.** KCl は強酸(HCl)の塩。弱酸の CH<sub>3</sub>COOH では強酸を追い出せない。ほかは「弱い方が追い出される」反応が起こる。

ひっかけ: (a) 弱酸の遊離の見落とし / (b) 弱塩基の遊離の見落とし / (c) 弱酸の遊離の見落とし

**Q6.** NaCl + H<sub>2</sub>SO<sub>4</sub> → NaHSO<sub>4</sub> + HCl。不揮発性の硫酸が、揮発性の塩酸(HCl)を追い出す。

ひっかけ: (a) 揮発性の酸の遊離の誤り / (c) 生成物の誤り / (d) 生成物の誤り

**Q7.** FeS + 2HCl → FeCl<sub>2</sub> + H<sub>2</sub>S。H<sub>2</sub>S は弱酸なので、強酸の HCl に追い出される(弱酸の遊離)。

ひっかけ: (a) 金属と酸の反応との混同 / (b) 生成物の誤り / (d) 生成物の誤り

**Q8.** 弱酸+強塩基の塩 → 加水分解で OH<sup>−</sup> を生じて塩基性(CH<sub>3</sub>COO<sup>−</sup> + H<sub>2</sub>O ⇄ CH<sub>3</sub>COOH + OH<sup>−</sup>)。

ひっかけ: (b) 強弱の組み合わせの誤り / (c) 中性の塩との混同 / (d) 電離による H<sup>+</sup> の見落とし

**Q9.** NH<sub>4</sub>NO<sub>3</sub> は強酸+弱塩基の塩 → NH<sub>4</sub><sup>+</sup> の加水分解で弱酸性。NaHSO<sub>4</sub> も酸性だが、HSO<sub>4</sub><sup>−</sup> の電離によるもので加水分解ではない。

ひっかけ: (a) 中性の塩との混同 / (b) 電離と加水分解の混同 / (d) 強弱の組み合わせの誤り

**Q10.** Zn + 2HCl → ZnCl<sub>2</sub> + H<sub>2</sub>。ほかにも 酸+塩基性酸化物、酸性酸化物+塩基、非金属+金属(Fe + S → FeS)などで塩ができる。

## ここを押さえる

- 塩の反応は「弱い方・揮発しやすい方が追い出される」。
- 塩の液性は、もとの酸・塩基の「強い方」の性質になる。
