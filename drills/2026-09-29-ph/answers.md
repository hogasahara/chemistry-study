## 解説

**Q1.** [H<sup>+</sup>] = 1.0×10<sup>−14</sup> ÷ 5.0×10<sup>−9</sup> = 2.0×10<sup>−6</sup> mol/L ＞ 1.0×10<sup>−7</sup> → 酸性。[OH<sup>−</sup>] が 10<sup>−7</sup> より小さければ酸性、と覚えてもよい。

ひっかけ: (b) 液性の判断の誤り / (c) [H<sup>+</sup>] と [OH<sup>−</sup>] の取り違え / (d) K<sub>w</sub> の使い忘れ

**Q2.** [H<sup>+</sup>] = 1.0×10<sup>−14</sup> ÷ 1.0×10<sup>−4</sup> = 1.0×10<sup>−10</sup> → pH 10。定石: 塩基は pH = 14 − (OH<sup>−</sup> の指数)。

ひっかけ: (a) [H<sup>+</sup>] と [OH<sup>−</sup>] の取り違え / (c) 計算の誤り / (d) 計算の誤り

**Q3.** [H<sup>+</sup>] = 0.0050 × 2 = 1.0×10<sup>−2</sup> mol/L → pH 2.0。硫酸は2価なので ×2 を忘れない。

ひっかけ: (a) 価数の誤り / (b) 桁ミス / (c) 桁ミス

**Q4.** [H<sup>+</sup>] = 0.050 × 1 × 0.020 = 1.0×10<sup>−3</sup> mol/L → pH 3.0。弱酸は電離度を掛ける。

ひっかけ: (a) 電離度の掛け忘れ / (c) 計算の誤り / (d) 計算の誤り

**Q5.** 濃度 = 0.020 ÷ 0.200 = 0.10 mol/L。[OH<sup>−</sup>] = 0.10 × 0.010 = 1.0×10<sup>−3</sup> → [H<sup>+</sup>] = 1.0×10<sup>−11</sup> → pH 11。

ひっかけ: (a) [H<sup>+</sup>] と [OH<sup>−</sup>] の取り違え / (c) 物質量をそのまま濃度にした / (d) 電離度の掛け忘れ

**Q6.** [H<sup>+</sup>] = 0.020 × 0.020 = 4.0×10<sup>−4</sup> mol/L。pH = −log(2<sup>2</sup>×10<sup>−4</sup>) = 4 − 2×0.30 = 3.4。定石: 4 = 2<sup>2</sup> なので log 4 = 0.60。

ひっかけ: (a) log の計算の誤り / (b) 電離度の掛け忘れ / (c) log の計算の誤り

**Q7.** [H<sup>+</sup>] が 1/100 → 10<sup>−3</sup> から 10<sup>−5</sup> へ。pH は 2 大きくなる。

**Q8.** 酸をいくらうすめても塩基性にはならない。pH は 7 に近づくだけ(水自身の H<sup>+</sup> 1.0×10<sup>−7</sup> mol/L があるため)。

**Q9.** pH が小さい = [H<sup>+</sup>] が大きい。硫酸は強酸かつ2価で [H<sup>+</sup>] = 0.20 mol/L と最大。

ひっかけ: (a) 価数の見落とし / (b) 強弱の誤り / (d) pH の大小の取り違え

**Q10.** H<sup>+</sup> = 1.0×10<sup>−2</sup>×0.100 + 1.0×10<sup>−4</sup>×0.100 ≒ 1.0×10<sup>−3</sup> mol。体積 0.200 L → [H<sup>+</sup>] ≒ 5.0×10<sup>−3</sup> mol/L → pH = 3 − log 5 = 3 − 0.70 = 2.3。pH は平均できない(mol で足す)。

ひっかけ: (a) pH を平均した / (c) うすまりを忘れた / (d) 計算の誤り

## ここを押さえる

- [H<sup>+</sup>] = 濃度 × 価数 × 電離度 → pH = −log[H<sup>+</sup>]。塩基は [OH<sup>−</sup>] を出してから K<sub>w</sub> で [H<sup>+</sup>] に直す。
- うすめると pH は 7 に近づくだけ。混合は mol で足して体積で割る。
