# 基礎⑦ 物質量とモル質量・粒子の数

分野: 物質量(基礎) ・ 出典: 基礎(mol の土台。プリント範囲の計算の前提) ・ 目安 7分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 物質量 [mol] | 6.0×10<sup>23</sup> 個の粒子の集まりを 1 mol とした量 |
| アボガドロ定数 | 6.0×10<sup>23</sup> /mol |
| 分子量・式量 | 化学式に含まれる原子の原子量の合計(例: H<sub>2</sub>O = 18) |
| モル質量 [g/mol] | 1 mol あたりの質量。分子量・式量に g/mol を付けたもの |
| 質量 → 物質量 | mol = 質量 [g] ÷ モル質量 [g/mol] |
| 物質量 → 粒子の数 | 個数 = mol × 6.0×10<sup>23</sup> |

## 設問

所要時間を測ってから始める。

**Q1.** 【計算】 二酸化炭素 CO<sub>2</sub> の分子量はいくらか。原子量は H = 1.0、C = 12、O = 16、Na = 23、Ca = 40 とする。

- (a) 28
- (b) 44
- (c) 60
- (d) 32

**Q2.** 【計算】 水酸化ナトリウム NaOH の式量はいくらか。原子量は H = 1.0、C = 12、O = 16、Na = 23、Ca = 40 とする。

- (a) 17
- (b) 39
- (c) 40
- (d) 63

**Q3.** 【計算】 水 H<sub>2</sub>O 36 g は何 mol か。原子量は H = 1.0、C = 12、O = 16、Na = 23、Ca = 40 とする。

- (a) 2.0 mol
- (b) 0.50 mol
- (c) 648 mol
- (d) 36 mol

**Q4.** 【計算】 NaOH 0.25 mol は何 g か。原子量は H = 1.0、C = 12、O = 16、Na = 23、Ca = 40 とする。

- (a) 160 g
- (b) 10 g
- (c) 6.3×10<sup>−3</sup> g
- (d) 40 g

**Q5.** 【計算】 1.5 mol の水分子は何個か。アボガドロ定数は 6.0×10<sup>23</sup> /mol とする。

- (a) 4.0×10<sup>23</sup>
- (b) 6.0×10<sup>23</sup>
- (c) 2.5×10<sup>−24</sup>
- (d) 9.0×10<sup>23</sup>

**Q6.** 【計算】 水分子 3.0×10<sup>23</sup> 個の質量は何 g か。原子量は H = 1.0、C = 12、O = 16、Na = 23、Ca = 40 とする。 アボガドロ定数は 6.0×10<sup>23</sup> /mol。

- (a) 9.0 g
- (b) 18 g
- (c) 36 g
- (d) 0.50 g

**Q7.** 【計算】 炭酸カルシウム CaCO<sub>3</sub> 5.0 g は何 mol か。原子量は H = 1.0、C = 12、O = 16、Na = 23、Ca = 40 とする。

- (a) 0.50 mol
- (b) 20 mol
- (c) 0.050 mol
- (d) 500 mol

**Q8.** 【計算】 CO<sub>2</sub> 0.20 mol に含まれる O 原子は何個か。アボガドロ定数は 6.0×10<sup>23</sup> /mol とする。

- (a) 1.2×10<sup>23</sup>
- (b) 2.4×10<sup>23</sup>
- (c) 3.6×10<sup>23</sup>
- (d) 2.4×10<sup>24</sup>
