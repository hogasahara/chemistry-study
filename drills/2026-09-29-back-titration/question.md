# 確認ドリル #1 — 逆滴定

分野: 酸と塩基 ・ 出典: プリント 酸塩基15〜17 ・ 目安 15分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 逆滴定 | 過剰の酸(塩基)に試料を反応させ、残った酸(塩基)を滴定して試料の量を求める方法 |
| 逆滴定の関係式 | 酸の H<sup>+</sup> の総物質量 = 塩基の OH<sup>−</sup> の総物質量(塩基側は NH<sub>3</sub> と NaOH の合計) |
| H<sub>2</sub>SO<sub>4</sub> | 硫酸(2価の強酸) |
| NH<sub>3</sub> | アンモニア(1価の弱塩基) |
| (NH<sub>4</sub>)<sub>2</sub>SO<sub>4</sub> | 硫酸アンモニウム(式量132) |
| 弱塩基の遊離 | 弱塩基の塩 + 強塩基 → 強塩基の塩 + 弱塩基 |
| メチルレッド | 変色域が酸性側の指示薬。NH<sub>3</sub> の逆滴定で使う |

**Q9.** 【用語】 アンモニアの逆滴定で、残った硫酸を NaOH で滴定するときの指示薬にメチルレッドを使う理由として正しいものはどれか。
