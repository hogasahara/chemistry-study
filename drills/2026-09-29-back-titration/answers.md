## 解説

**Q1.** アンモニアは塩基なので NaOH(塩基)では滴定できない。過剰の硫酸に吸収させ、残った硫酸を NaOH で滴定する(逆滴定)。

**Q2.** 硫酸の H<sup>+</sup> を、NH<sub>3</sub> と NaOH の2つが分け合って中和している。図の「長い矢印 = 短い矢印2本の合計」をイメージする。

**Q3.** 左辺は酸の H<sup>+</sup>(硫酸は2価なので ×2)、右辺は塩基の OH<sup>−</sup>(NaOH も NH<sub>3</sub> も1価)。

ひっかけ: (a) 価数の誤り / (c) 酸と塩基の取り違え / (d) 価数の誤り

**Q4.** H<sup>+</sup> = 0.100×(10.0/1000)×2 = 2.00×10<sup>−3</sup> mol。NaOH = 0.100×(8.0/1000) = 8.0×10<sup>−4</sup> mol。NH<sub>3</sub> = 2.00×10<sup>−3</sup> − 8.0×10<sup>−4</sup> = 1.2×10<sup>−3</sup> mol。定石: mL は必ず ÷1000 して L にしてから掛ける。

ひっかけ: (a) 価数の誤り / (b) 足し引きの逆 / (d) 桁ミス

**Q5.** 酸の H<sup>+</sup> = 塩基の OH<sup>−</sup> より、x×(20.0/1000) + 0.0200×(5.00/1000)×2 = 0.100×(10.0/1000)。x×0.0200 = 1.00×10<sup>−3</sup> − 2.00×10<sup>−4</sup> = 8.00×10<sup>−4</sup> → x = 0.0400 mol/L。酸が2種類(塩酸と硫酸)でも、左辺に全部まとめればよい。

ひっかけ: (b) 価数の誤り / (c) 足し引きの逆 / (d) 桁ミス

**Q6.** (NH<sub>4</sub>)<sub>2</sub>SO<sub>4</sub> は強酸(H<sub>2</sub>SO<sub>4</sub>)と弱塩基(NH<sub>3</sub>)の塩。強塩基 NaOH を加えると弱塩基 NH<sub>3</sub> が追い出される(弱塩基の遊離)。

ひっかけ: (a) 塩の分類の誤り / (c) 酸と塩基の取り違え / (d) 強弱の逆

**Q7.** (NH<sub>4</sub>)<sub>2</sub>SO<sub>4</sub> 1個に NH<sub>4</sub> が2つ → NH<sub>3</sub> は 2。つまり「塩 1 mol から NH<sub>3</sub> 2 mol」。質量%の計算で使う大事な比。

ひっかけ: (a) 係数の誤り / (b) 係数の誤り / (c) 係数の誤り

**Q8.** H<sup>+</sup> = 0.500×(50.0/1000)×2 = 0.0500 mol、NaOH = 1.00×(26.0/1000) = 0.0260 mol → NH<sub>3</sub> = 0.0240 mol。塩は NH<sub>3</sub> の半分で 0.0120 mol → 0.0120×132 = 1.584 g。1.584 ÷ 3.00 × 100 ≒ 53%。

ひっかけ: (a) NaOH を NH<sub>3</sub> と取り違え / (b) 係数の誤り / (c) 桁ミス

**Q9.** 中和点には強酸と弱塩基の塩 (NH<sub>4</sub>)<sub>2</sub>SO<sub>4</sub> が残るので弱酸性。変色域が酸性側のメチルレッド(またはメチルオレンジ)を使う。

ひっかけ: (b) 中和点の液性の誤り / (c) 指示薬のしくみの誤り / (d) 中和点の液性の誤り

## ここを押さえる

- 逆滴定は「酸の H<sup>+</sup> の合計 = 塩基の OH<sup>−</sup> の合計」を書くだけ。酸・塩基が何種類あっても、左右に全部並べる。
- 硫酸は2価(×2)を忘れない。(NH<sub>4</sub>)<sub>2</sub>SO<sub>4</sub> 1 mol ↔ NH<sub>3</sub> 2 mol。
