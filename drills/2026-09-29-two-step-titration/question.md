# 確認ドリル #2 — 二段階滴定

分野: 酸と塩基 ・ 出典: プリント 酸塩基18〜19 ・ 目安 15分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 二段階滴定 | Na<sub>2</sub>CO<sub>3</sub> を塩酸で滴定するときのように、中和点が2か所ある滴定 |
| 第1中和点 | CO<sub>3</sub><sup>2−</sup> + H<sup>+</sup> → HCO<sub>3</sub><sup>−</sup> が終わる点。フェノールフタレインで見る(赤→無色) |
| 第2中和点 | HCO<sub>3</sub><sup>−</sup> + H<sup>+</sup> → H<sub>2</sub>O + CO<sub>2</sub> が終わる点。メチルオレンジで見る(黄→赤) |
| Na<sub>2</sub>CO<sub>3</sub> | 炭酸ナトリウム |
| NaHCO<sub>3</sub> | 炭酸水素ナトリウム(水溶液は弱い塩基性) |
| ワルダー法 | NaOH と Na<sub>2</sub>CO<sub>3</sub> の混合物を二段階滴定で定量する方法 |
| 2NaOH + CO<sub>2</sub> → Na<sub>2</sub>CO<sub>3</sub> + H<sub>2</sub>O | NaOH が空気中の CO<sub>2</sub> と反応して一部が Na<sub>2</sub>CO<sub>3</sub> になる |

## 設問

所要時間を測ってから始める。

**Q1.** Na<sub>2</sub>CO<sub>3</sub> 水溶液を塩酸で滴定するとき、第1中和点までに使う塩酸の体積と、第1中和点から第2中和点までに使う塩酸の体積は等しい。

正 / 誤

**Q2.** 第1中和点の水溶液は酸性である。

正 / 誤

**Q3.** 【反応式】 第1中和点までの反応 Na<sub>2</sub>CO<sub>3</sub> + HCl → NaCl + 【 ア 】 のアに入るものはどれか。

- (a) H<sub>2</sub>O + CO<sub>2</sub>
- (b) NaOH
- (c) NaHCO<sub>3</sub>
- (d) H<sub>2</sub>CO<sub>3</sub>

**Q4.** 【組み合わせ】 Na<sub>2</sub>CO<sub>3</sub> 水溶液にフェノールフタレインを加えて塩酸で滴定し、第1中和点のあとメチルオレンジを加えてさらに滴定した。第1中和点・第2中和点での溶液の色の変化の組み合わせとして正しいものはどれか。

- (a) 第1: 無色→赤色 ・ 第2: 黄色→赤色
- (b) 第1: 赤色→無色 ・ 第2: 赤色→黄色
- (c) 第1: 無色→赤色 ・ 第2: 赤色→黄色
- (d) 第1: 赤色→無色 ・ 第2: 黄色→赤色

**Q5.** 【計算】 濃度のわからない Na<sub>2</sub>CO<sub>3</sub> 水溶液 20.0 mL を 0.100 mol/L の塩酸で滴定したところ、第1中和点までに 12.0 mL を要した。Na<sub>2</sub>CO<sub>3</sub> 水溶液のモル濃度は何 mol/L か。

- (a) 0.120 mol/L
- (b) 0.0600 mol/L
- (c) 0.0300 mol/L
- (d) 0.600 mol/L

**Q6.** 【計算】 前の問題と同じ滴定で、滴定開始から第2中和点までに加えた塩酸は合計何 mL か。

- (a) 12.0 mL
- (b) 36.0 mL
- (c) 24.0 mL
- (d) 6.0 mL

**Q7.** 【組み合わせ】 NaOH と Na<sub>2</sub>CO<sub>3</sub> の混合水溶液を塩酸で二段階滴定した。次の記述 a・b の正誤の組み合わせとして正しいものはどれか。<br>a 第1中和点までに、NaOH と Na<sub>2</sub>CO<sub>3</sub> の両方が塩酸と反応する。<br>b 第1中和点から第2中和点までに塩酸と反応するのは NaOH である。

- (a) a 正 ・ b 正
- (b) a 正 ・ b 誤
- (c) a 誤 ・ b 正
- (d) a 誤 ・ b 誤

**Q8.** 【計算】 NaOH と Na<sub>2</sub>CO<sub>3</sub> の混合水溶液 20.0 mL を 0.500 mol/L の塩酸で滴定した。第1中和点までに 10.0 mL、第1中和点から第2中和点までに 3.0 mL を要した。混合水溶液中の Na<sub>2</sub>CO<sub>3</sub> は何 mol か。

- (a) 1.5×10<sup>−3</sup> mol
- (b) 5.0×10<sup>−3</sup> mol
- (c) 6.5×10<sup>−3</sup> mol
- (d) 3.0×10<sup>−3</sup> mol

**Q9.** 【計算】 前の問題と同じ滴定で、混合水溶液中の NaOH は何 mol か。

- (a) 5.0×10<sup>−3</sup> mol
- (b) 3.5×10<sup>−2</sup> mol
- (c) 2.0×10<sup>−3</sup> mol
- (d) 3.5×10<sup>−3</sup> mol
