## 解説

**Q1.** 第1段階で Na<sub>2</sub>CO<sub>3</sub> と同じ物質量の NaHCO<sub>3</sub> ができ、第2段階でそれが全部反応する。どちらも Na<sub>2</sub>CO<sub>3</sub> と同じ物質量の HCl を使う。

**Q2.** 第1中和点には NaHCO<sub>3</sub> ができているので弱い塩基性(だからフェノールフタレインで見る)。酸性になるのは CO<sub>2</sub> ができる第2中和点。

**Q3.** CO<sub>3</sub><sup>2−</sup> はまず H<sup>+</sup> を1個だけ受け取って HCO<sub>3</sub><sup>−</sup> になる(NaHCO<sub>3</sub>)。H<sub>2</sub>O + CO<sub>2</sub> になるのは第2段階。

ひっかけ: (a) 第1段階と第2段階の混同 / (b) 生成物の誤り / (d) 第1段階と第2段階の混同

**Q4.** 酸を加えていくので pH は下がる。フェノールフタレインは塩基性で赤 → 無色、メチルオレンジは塩基〜中性側で黄 → 酸性で赤。定石: 「酸で滴定 → 塩基性の色から酸性の色へ」。

ひっかけ: (a) 色の変化の向きの逆 / (b) 色の変化の向きの逆 / (c) 色の変化の向きの逆

**Q5.** 第1段階は Na<sub>2</sub>CO<sub>3</sub> : HCl = 1 : 1。0.100×(12.0/1000) = 1.20×10<sup>−3</sup> mol → ÷(20.0/1000) = 0.0600 mol/L。第1段階だけを見るときは Na<sub>2</sub>CO<sub>3</sub> を「1価」として扱う。

ひっかけ: (a) 第2中和点までの量を使った / (c) 価数の誤り / (d) 桁ミス

**Q6.** 第1段階と第2段階で使う塩酸は同じ量(12.0 mL ずつ)なので、合計 24.0 mL。

ひっかけ: (a) 第1段階だけで考えた / (b) 段階の数の誤り / (d) 第1段階と第2段階の関係の誤り

**Q7.** 第1段階: 強塩基の NaOH の中和と、Na<sub>2</sub>CO<sub>3</sub> → NaHCO<sub>3</sub>(a は正)。第2段階で反応するのは NaHCO<sub>3</sub> だけ(b は誤)。

ひっかけ: (a) 段階ごとの反応の混同 / (c) 段階ごとの反応の混同 / (d) 段階ごとの反応の混同

**Q8.** 第2段階(3.0 mL)で反応するのは NaHCO<sub>3</sub> だけで、その量は元の Na<sub>2</sub>CO<sub>3</sub> と同じ。0.500×(3.0/1000) = 1.5×10<sup>−3</sup> mol。

ひっかけ: (b) 第1中和点までの量を使った / (c) 合計量を使った / (d) 価数の誤り

**Q9.** 第1段階の 10.0 mL には Na<sub>2</sub>CO<sub>3</sub> の分(第2段階と同じ 3.0 mL)が含まれる。NaOH の分は 10.0 − 3.0 = 7.0 mL → 0.500×(7.0/1000) = 3.5×10<sup>−3</sup> mol。定石: 図の a − b。

ひっかけ: (a) Na<sub>2</sub>CO<sub>3</sub> の分を引き忘れ / (b) 桁ミス / (c) Na<sub>2</sub>CO<sub>3</sub> の分を2回引いた

## ここを押さえる

- Na<sub>2</sub>CO<sub>3</sub> は「H<sup>+</sup> を1個ずつ2回受け取る」。第1段階と第2段階の酸の量は等しい。
- 混合塩基(ワルダー法): Na<sub>2</sub>CO<sub>3</sub> は第2段階の量 b から、NaOH は a − b から求める。
