## 解説

**Q1.** K: 0(単体)→ +1(KBr)。酸化数が増加 → 酸化された。

ひっかけ: (b) 増減と酸化・還元の対応の誤り / (c) 酸化数の計算の誤り / (d) 定義の誤り

**Q2.** Cl: 0 → −1。酸化数が減少 → 還元された(Br は −1 → 0 で酸化された)。

ひっかけ: (a) 増減と酸化・還元の対応の誤り / (c) 酸化数の計算の誤り / (d) 定義の誤り

**Q3.** Cu: +2(CuO)→ +2(CuSO<sub>4</sub>)で変化なし → いずれでもない。この反応は酸化還元反応ではない(塩基性酸化物と酸の反応)。

ひっかけ: (a) O の数だけで判断 / (b) O の数だけで判断 / (d) 定義の誤り

**Q4.** 電子を受け取った(酸化数 +2 → 0)→ 還元された。

ひっかけ: (a) 電子の授受の向きの誤り / (c) 定義の誤り / (d) 定義の誤り

**Q5.** 中和反応では酸化数が変化しない。定石: 反応式に単体が出てくれば(出入りすれば)ほぼ酸化還元反応。

ひっかけ: (a) 単体の出入りの見落とし / (b) 単体の出入りの見落とし / (d) 単体の出入りの見落とし

**Q6.** I: −1(KI)→ 0(I<sub>2</sub>)で酸化された。O: −1(H<sub>2</sub>O<sub>2</sub>)→ −2(H<sub>2</sub>O)で還元された。K・S・H は変化なし。

ひっかけ: (b) 増減と酸化・還元の対応の誤り / (c) 酸化数の計算の誤り / (d) 酸化数の計算の誤り

**Q7.** Fe: +3 → 0(減少)で還元された。Al: 0 → +3 で酸化された。O は −2 のまま。

ひっかけ: (a) 増減と酸化・還元の対応の誤り / (b) 酸化数の計算の誤り / (d) 同時性の見落とし

**Q8.** HNO<sub>3</sub> の N: +1 + x − 6 = 0 → +5。NO<sub>2</sub> の N: x − 4 = 0 → +4。減少したので還元された。Cu(NO<sub>3</sub>)<sub>2</sub> 中の N は +5 のまま。

ひっかけ: (b) 変化の向きの誤り / (c) NO と混同 / (d) 酸化数の計算の誤り

**Q9.** 酸化数が増加 → 酸化された。減少 → 還元された。

**Q10.** H<sub>2</sub> になった H は +1 → 0 に減少(還元された)。NaOH に残った H は +1 のまま。Na は 0 → +1 で酸化された。

## ここを押さえる

- 酸化数 増加 = 酸化された、減少 = 還元された。
- 同じ元素でも、変化した原子と変化しない原子がある(HNO<sub>3</sub> の N、H<sub>2</sub>O の H など)。
