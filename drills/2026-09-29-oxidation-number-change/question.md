# 確認ドリル #11 — 酸化数の変化

分野: 酸化還元 ・ 出典: プリント 酸化還元3 ・ 目安 12分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 酸化数が増加 | その原子(物質)は酸化された |
| 酸化数が減少 | その原子(物質)は還元された |
| 酸化還元反応かどうか | 酸化数が変化した原子があれば酸化還元反応。中和反応などは変化しない |
| e<sup>−</sup> を放出する式 | 例: Zn → Zn<sup>2+</sup> + 2e<sup>−</sup>(酸化) |
| e<sup>−</sup> を受け取る式 | 例: Cu<sup>2+</sup> + 2e<sup>−</sup> → Cu(還元) |
