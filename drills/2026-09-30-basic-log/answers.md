## 解説

**Q1.** [H<sup>+</sup>] = 1.0×10<sup>−n</sup> なら pH = n。

ひっかけ: (b) 符号の誤り / (c) [H<sup>+</sup>] と [OH<sup>−</sup>] の取り違え / (d) pH の定義の誤り

**Q2.** pH = n なら [H<sup>+</sup>] = 1.0×10<sup>−n</sup>。

ひっかけ: (a) 符号の誤り / (c) [H<sup>+</sup>] と [OH<sup>−</sup>] の取り違え / (d) pH の定義の誤り

**Q3.** pH 9 で、7 より大きい → 塩基性。[H<sup>+</sup>] が 10<sup>−7</sup> より小さい。

ひっかけ: (a) pH の大小の取り違え / (b) 液性の判断の誤り / (d) 液性の判断の誤り

**Q4.** [H<sup>+</sup>] = 1.0×10<sup>−14</sup> ÷ 1.0×10<sup>−2</sup> = 1.0×10<sup>−12</sup> → pH 12。

ひっかけ: (a) [H<sup>+</sup>] と [OH<sup>−</sup>] の取り違え / (b) 符号の誤り / (c) 中性と混同

**Q5.** pH = −log(2.0×10<sup>−3</sup>) = −(log 2 + log 10<sup>−3</sup>) = −(0.30 − 3) = 2.7。定石: 係数が1より大きいと pH は n より小さくなる。

ひっかけ: (b) log の足し引きの逆 / (c) log の計算の誤り / (d) 係数を無視した

**Q6.** log 5 = 1 − log 2 = 0.70。pH = −(0.70 − 4) = 3.3。

ひっかけ: (a) log の足し引きの逆 / (c) log 2 と log 5 の混同 / (d) 係数を無視した

**Q7.** pH が 1 小さいと 10 倍、2 小さいと 10×10 = 100 倍。

**Q8.** 10<sup>−3</sup> ÷ 10<sup>−5</sup> = 10<sup>2</sup> = 100 倍。

ひっかけ: (a) pH の差をそのまま使った / (b) 計算の誤り / (d) 計算の誤り

## ここを押さえる

- pH = n ↔ [H<sup>+</sup>] = 1.0×10<sup>−n</sup>。
- 係数つきは log(a×10<sup>−n</sup>) = log a − n。log 2 = 0.30、log 5 = 0.70。
