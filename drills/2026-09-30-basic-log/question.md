# 基礎③ pH と指数・対数

分野: 酸と塩基(基礎) ・ 出典: 基礎(pH の計算の前提) ・ 目安 6分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| [H<sup>+</sup>] = 1.0×10<sup>−n</sup> mol/L | pH = n |
| log<sub>10</sub>2 | 0.30 |
| log<sub>10</sub>5 | 0.70(= 1 − log<sub>10</sub>2) |
| log(a×b) | log a + log b |
| [H<sup>+</sup>]×[OH<sup>−</sup>] | 1.0×10<sup>−14</sup>(25℃) |
| pH が 1 違う | [H<sup>+</sup>] は 10 倍違う |

## 設問

所要時間を測ってから始める。

**Q1.** 【計算】 [H<sup>+</sup>] = 1.0×10<sup>−3</sup> mol/L の水溶液の pH はいくらか。

- (a) 3
- (b) −3
- (c) 11
- (d) 0.001

**Q2.** 【計算】 pH 5 の水溶液の [H<sup>+</sup>] は何 mol/L か。

- (a) 1.0×10<sup>5</sup>
- (b) 1.0×10<sup>−5</sup>
- (c) 1.0×10<sup>−9</sup>
- (d) 5

**Q3.** 【用語】 [H<sup>+</sup>] = 1.0×10<sup>−9</sup> mol/L の水溶液の液性はどれか(25℃)。

- (a) 酸性
- (b) 中性
- (c) 塩基性
- (d) 判断できない

**Q4.** 【計算】 [OH<sup>−</sup>] = 1.0×10<sup>−2</sup> mol/L のとき、[H<sup>+</sup>] は何 mol/L か(25℃)。

- (a) 1.0×10<sup>−2</sup>
- (b) 1.0×10<sup>12</sup>
- (c) 1.0×10<sup>−7</sup>
- (d) 1.0×10<sup>−12</sup>

**Q5.** 【計算】 [H<sup>+</sup>] = 2.0×10<sup>−3</sup> mol/L の水溶液の pH はいくらか。log<sub>10</sub>2 = 0.30 とする。

- (a) 2.7
- (b) 3.3
- (c) 2.3
- (d) 3.0

**Q6.** 【計算】 [H<sup>+</sup>] = 5.0×10<sup>−4</sup> mol/L の水溶液の pH はいくらか。log<sub>10</sub>2 = 0.30 とする。

- (a) 4.7
- (b) 3.3
- (c) 3.7
- (d) 4.0

**Q7.** pH が 2 小さくなると、[H<sup>+</sup>] は 100 倍になる。

正 / 誤

**Q8.** 【計算】 pH 3 の水溶液の [H<sup>+</sup>] は、pH 5 の水溶液の何倍か。

- (a) 2 倍
- (b) 20 倍
- (c) 100 倍
- (d) 1000 倍
