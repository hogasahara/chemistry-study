| Q2 | (a) 水溶液中で電離して OH<sup>−</sup> を生じる物質 |
| Q3 | (b) 塩基 |
| Q4 | (c) 酸 |
| Q5 | (a) H<sub>2</sub>SO<sub>4</sub> と (COOH)<sub>2</sub> |
| Q6 | (c) NH<sub>3</sub> |
| Q7 | (b) 0.020 |
| Q8 | 誤 |
| Q9 | (d) 第1段階の電離は起こりやすいが、それ以降は起こりにくい |
| Q10 | (c) オキソニウムイオン |

## 解説

**Q1.** 酸: リトマス 青→赤、BTB 黄。塩基: リトマス 赤→青、BTB 青。

**Q2.** アレニウスは「水溶液中で何を出すか」(H<sup>+</sup> なら酸、OH<sup>−</sup> なら塩基)。ブレンステッド・ローリーは「H<sup>+</sup> をやりとりする向き」。

ひっかけ: (b) 定義の取り違え(ブレンステッド・ローリー) / (c) 酸と塩基の取り違え / (d) 酸と塩基の取り違え

**Q3.** H<sub>2</sub>O は CH<sub>3</sub>COOH から H<sup>+</sup> を受け取って H<sub>3</sub>O<sup>+</sup> になった → 塩基。定石: H<sup>+</sup> の矢印を書いて、渡した側が酸、受け取った側が塩基。

ひっかけ: (a) H<sup>+</sup> の向きの取り違え / (c) 定義の誤り / (d) 定義の誤り

**Q4.** H<sub>2</sub>O が CO<sub>3</sub><sup>2−</sup> に H<sup>+</sup> を与えて OH<sup>−</sup> になった → 酸。水は相手によって酸にも塩基にもなる。

ひっかけ: (a) H<sup>+</sup> の向きの取り違え / (b) 定義の誤り / (d) 定義の誤り

**Q5.** 硫酸・シュウ酸 (COOH)<sub>2</sub>・炭酸・硫化水素が2価。酢酸 CH<sub>3</sub>COOH は H を4つ持つが、出せるのは COOH の1つだけなので1価。

ひっかけ: (b) 価数の誤り / (c) 価数の誤り / (d) H の数で価数を数えた

**Q6.** 強塩基は NaOH・KOH・Ca(OH)<sub>2</sub>・Ba(OH)<sub>2</sub>。NH<sub>3</sub> は弱塩基(電離度が小さい)。価数と強弱は別の話。

ひっかけ: (a) 価数と強弱の混同 / (b) 強弱の誤り / (d) 価数と強弱の混同

**Q7.** α = 電離した量 ÷ 溶かした量 = 1.0×10<sup>−3</sup> ÷ 0.050 = 0.020。答えは必ず 0 ＜ α ≦ 1 になるので、50 はありえない。

ひっかけ: (a) 割らずに掛けた / (c) 割り算の逆 / (d) 桁ミス

**Q8.** 弱酸は濃度が小さい(うすい)ほど電離度が大きくなり、1 に近づく(プリントのグラフ)。

**Q9.** H<sub>2</sub>CO<sub>3</sub> ⇄ H<sup>+</sup> + HCO<sub>3</sub><sup>−</sup>(起こりやすい)→ HCO<sub>3</sub><sup>−</sup> ⇄ H<sup>+</sup> + CO<sub>3</sub><sup>2−</sup>(起こりにくい)。

ひっかけ: (a) 段階的な電離の誤り / (b) 段階的な電離の誤り / (c) 段階的な電離の誤り

**Q10.** H<sub>2</sub>O が H<sup>+</sup> を受け取ると H<sub>3</sub>O<sup>+</sup>(オキソニウムイオン)。水溶液中の H<sup>+</sup> は実際はこの形で存在する。

ひっかけ: (a) イオンの名前の誤り / (b) イオンの名前の誤り / (d) イオンの名前の誤り

## ここを押さえる

- ブレンステッド・ローリーは「H<sup>+</sup> の矢印」を書く: 渡した側が酸、受け取った側が塩基。
- 価数(いくつ出せるか)と強弱(どれだけ電離するか)は別。
