# 確認ドリル #8 — 酸・塩基の定義と電離度

分野: 酸と塩基 ・ 出典: プリント 酸塩基1〜2 ・ 目安 12分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 酸の性質 | すっぱい味。青色リトマス紙を赤に、BTB を黄色にする。金属と反応して H<sub>2</sub> を発生 |
| 塩基の性質 | 苦い味。赤色リトマス紙を青に、BTB を青色にする。手につけるとぬるぬるする |
| アレニウスの定義 | 酸: 水溶液中で電離して H<sup>+</sup> を生じる物質 / 塩基: 水溶液中で電離して OH<sup>−</sup> を生じる物質 |
| ブレンステッド・ローリーの定義 | 酸: H<sup>+</sup>(陽子)を与える物質 / 塩基: H<sup>+</sup>(陽子)を受け取る物質 |
| H<sub>3</sub>O<sup>+</sup> | オキソニウムイオン |
| 価数 | 酸・塩基1つが出せる H<sup>+</sup> や OH<sup>−</sup> の数 |
| 電離度 α | 電離した酸(塩基)の量 ÷ 溶かした酸(塩基)の量(0 ＜ α ≦ 1) |
| 強酸 | HCl, HNO<sub>3</sub>, H<sub>2</sub>SO<sub>4</sub>(α ≒ 1) |
| 強塩基 | NaOH, KOH, Ca(OH)<sub>2</sub>, Ba(OH)<sub>2</sub>(α ≒ 1) |

## 設問

所要時間を測ってから始める。

**Q1.** 酸の水溶液は、青色リトマス紙を赤色に変え、BTB 溶液を黄色にする。

正 / 誤

**Q2.** 【用語】 アレニウスの定義による「塩基」の説明として正しいものはどれか。

- (a) 水溶液中で電離して OH<sup>−</sup> を生じる物質
- (b) H<sup>+</sup> を受け取る物質
- (c) H<sup>+</sup> を与える物質
- (d) 水溶液中で電離して H<sup>+</sup> を生じる物質

**Q3.** 【用語】 CH<sub>3</sub>COOH + H<sub>2</sub>O ⇄ CH<sub>3</sub>COO<sup>−</sup> + H<sub>3</sub>O<sup>+</sup> の右向きの反応で、H<sub>2</sub>O はどのような働きをしているか(ブレンステッド・ローリーの定義)。

- (a) 酸
- (b) 塩基
- (c) どちらでもない
- (d) 酸と塩基の両方

**Q4.** 【用語】 CO<sub>3</sub><sup>2−</sup> + H<sub>2</sub>O ⇄ HCO<sub>3</sub><sup>−</sup> + OH<sup>−</sup> の右向きの反応で、H<sub>2</sub>O はどのような働きをしているか。

- (a) 塩基
- (b) どちらでもない
- (c) 酸
- (d) 酸と塩基の両方

**Q5.** 【用語】 2価の酸の組み合わせとして正しいものはどれか。

- (a) H<sub>2</sub>SO<sub>4</sub> と (COOH)<sub>2</sub>
- (b) HNO<sub>3</sub> と H<sub>2</sub>S
- (c) H<sub>3</sub>PO<sub>4</sub> と H<sub>2</sub>CO<sub>3</sub>
- (d) CH<sub>3</sub>COOH と H<sub>2</sub>SO<sub>4</sub>

**Q6.** 【用語】 次のうち、弱塩基はどれか。

- (a) Ba(OH)<sub>2</sub>
- (b) KOH
- (c) NH<sub>3</sub>
- (d) Ca(OH)<sub>2</sub>

**Q7.** 【計算】 0.050 mol/L の酢酸水溶液の水素イオン濃度は 1.0×10<sup>−3</sup> mol/L であった。酢酸の電離度はいくらか。

- (a) 5.0×10<sup>−5</sup>
- (b) 0.020
- (c) 50
- (d) 0.20

**Q8.** 弱酸の水溶液は、うすめるほど電離度が小さくなる。

正 / 誤

**Q9.** 【用語】 炭酸 H<sub>2</sub>CO<sub>3</sub> のような多価の弱酸の電離について、正しいものはどれか。

- (a) 2つの H<sup>+</sup> が一度にまとめて電離する
- (b) 第2段階の電離の方が第1段階より起こりやすい
- (c) 第1段階と第2段階は同じ程度に起こる
- (d) 第1段階の電離は起こりやすいが、それ以降は起こりにくい

**Q10.** 【穴埋め】 HCl + H<sub>2</sub>O → 【 ア 】 + Cl<sup>−</sup> のアに入るイオンの名前はどれか。

- (a) アンモニウムイオン
- (b) 水酸化物イオン
- (c) オキソニウムイオン
- (d) 塩化物イオン
