## 解説

**Q1.** mL → L は ÷1000。25 ÷ 1000 = 0.025 L。

ひっかけ: (a) 桁ミス / (c) 桁ミス / (d) 桁ミス

**Q2.** 0.10 mol/L × 0.020 L = 0.0020 = 2.0×10<sup>−3</sup> mol。

ひっかけ: (a) mL を L に直し忘れ / (b) 桁ミス / (d) 割り算の逆

**Q3.** 0.030 mol ÷ 0.200 L = 0.15 mol/L。

ひっかけ: (b) 割らずに掛けた / (c) mL を L に直し忘れ / (d) 割り算の逆

**Q4.** 硫酸は 0.050 × 0.010 = 5.0×10<sup>−4</sup> mol。2価なので H<sup>+</sup> は ×2 で 1.0×10<sup>−3</sup> mol。

ひっかけ: (a) 価数の誤り / (c) mL を L に直し忘れ / (d) 桁ミス

**Q5.** 掛け算は指数を足す: (−2) + (−3) = −5。

ひっかけ: (b) 指数を掛けた / (c) 指数を引いた / (d) 指数を引いた

**Q6.** 割り算は指数を引く: (−14) − (−4) = −10。[OH<sup>−</sup>] から [H<sup>+</sup>] を出すときに使う。

ひっかけ: (a) 指数を足した / (b) 符号の誤り / (d) 計算の誤り

**Q7.** 小数点を右へ3つ動かすと 2.0 → ×10<sup>−3</sup>。

ひっかけ: (a) 桁ミス / (b) 符号の誤り / (c) 桁ミス

**Q8.** 必要な NaOH は 1.2×10<sup>−3</sup> mol。体積 = 1.2×10<sup>−3</sup> ÷ 0.10 = 0.012 L = 12 mL。

ひっかけ: (b) 桁ミス / (c) 桁ミス / (d) L のまま答えた

## ここを押さえる

- mol = mol/L × L。最初に mL を L に直す。
- 指数の掛け算は足す、割り算は引く。
