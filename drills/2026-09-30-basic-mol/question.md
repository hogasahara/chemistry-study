# 基礎② 物質量と濃度の計算

分野: 酸と塩基(基礎) ・ 出典: 基礎(中和・滴定の計算の前提) ・ 目安 6分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| mL → L | ÷1000(例: 20 mL = 0.020 L) |
| 物質量 [mol] | モル濃度 [mol/L] × 体積 [L] |
| モル濃度 [mol/L] | 物質量 [mol] ÷ 体積 [L] |
| 10<sup>a</sup> × 10<sup>b</sup> | 10<sup>a+b</sup>(指数は足す) |
| 10<sup>a</sup> ÷ 10<sup>b</sup> | 10<sup>a−b</sup>(指数は引く) |
| H<sup>+</sup> の物質量 | 酸の物質量 × 価数 |

## 設問

所要時間を測ってから始める。

**Q1.** 【計算】 25 mL は何 L か。

- (a) 0.25 L
- (b) 0.025 L
- (c) 2.5 L
- (d) 0.0025 L

**Q2.** 【計算】 0.10 mol/L の塩酸 20 mL に含まれる HCl は何 mol か。

- (a) 2.0 mol
- (b) 2.0×10<sup>−2</sup> mol
- (c) 2.0×10<sup>−3</sup> mol
- (d) 5.0×10<sup>−3</sup> mol

**Q3.** 【計算】 NaOH 0.030 mol を水に溶かして 200 mL にした。モル濃度は何 mol/L か。

- (a) 0.15 mol/L
- (b) 6.0×10<sup>−3</sup> mol/L
- (c) 1.5×10<sup>−4</sup> mol/L
- (d) 6.7 mol/L

**Q4.** 【計算】 0.050 mol/L の硫酸 10 mL から生じる H<sup>+</sup> は何 mol か。

- (a) 5.0×10<sup>−4</sup> mol
- (b) 1.0×10<sup>−3</sup> mol
- (c) 1.0 mol
- (d) 0.10 mol

**Q5.** 【計算】 (1.0×10<sup>−2</sup>) × (1.0×10<sup>−3</sup>) を計算するといくらか。

- (a) 1.0×10<sup>−5</sup>
- (b) 1.0×10<sup>−6</sup>
- (c) 1.0×10<sup>1</sup>
- (d) 1.0×10<sup>−1</sup>

**Q6.** 【計算】 (1.0×10<sup>−14</sup>) ÷ (1.0×10<sup>−4</sup>) を計算するといくらか。

- (a) 1.0×10<sup>−18</sup>
- (b) 1.0×10<sup>10</sup>
- (c) 1.0×10<sup>−10</sup>
- (d) 1.0×10<sup>−4</sup>

**Q7.** 【計算】 0.0020 を「□×10<sup>n</sup>」の形で表したものはどれか。

- (a) 2.0×10<sup>−2</sup>
- (b) 2.0×10<sup>3</sup>
- (c) 2.0×10<sup>−4</sup>
- (d) 2.0×10<sup>−3</sup>

**Q8.** 【計算】 HCl 1.2×10<sup>−3</sup> mol を中和するのに、0.10 mol/L の NaOH 水溶液は何 mL 必要か。

- (a) 12 mL
- (b) 1.2 mL
- (c) 120 mL
- (d) 0.012 mL
