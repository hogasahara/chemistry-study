## 解説

**Q1.** MO は酸性側で変色する指示薬。pH 3.1 以下で赤、4.4 以上で黄。

**Q2.** PP は pH 8.0 未満なので無色。MO は pH 4.4 より大きいので黄。定石: 数直線に変色域を書いて、pH の位置と比べる。

ひっかけ: (a) 変色域の誤り / (c) 変色域の誤り / (d) 変色域の誤り

**Q3.** H<sup>+</sup> と OH<sup>−</sup> の物質量が等しければ完全に中和する。強弱(電離度)とは無関係。

**Q4.** 中和が進むと残りの酢酸も次々に電離するので、最終的に 200 個すべてが中和される。酢酸は1価なので NaOH も 200 個。電離度はひっかけ。

ひっかけ: (a) 電離している分だけで計算 / (c) 電離していない分だけで計算 / (d) 価数の誤り

**Q5.** H<sup>+</sup> 2個と OH<sup>−</sup> 2個から H<sub>2</sub>O が2個できる。定石: 水の係数 = 中和した H<sup>+</sup>(OH<sup>−</sup>)の数。

ひっかけ: (a) 係数の誤り / (b) 係数の誤り / (c) 係数の誤り

**Q6.** リン酸は3価の酸 → NaOH(1価)が3つ必要。

ひっかけ: (a) 価数の誤り / (b) 価数の誤り / (d) 係数の誤り

**Q7.** HCl + NH<sub>3</sub> → NH<sub>4</sub>Cl。NH<sub>3</sub> は OH<sup>−</sup> を持たず H<sup>+</sup> を直接受け取るので、塩だけができる。

ひっかけ: (a) 中和の生成物の誤り / (b) 中和の生成物の誤り / (d) 中和の生成物の誤り

**Q8.** OH<sup>−</sup> = 1.5×2 = 3.0 mol。リン酸は3価なので 3.0 ÷ 3 = 1.0 mol。定石: 酸の mol × 価数 = 塩基の mol × 価数。

ひっかけ: (b) 価数の誤り / (c) 価数の誤り / (d) 価数を反対側に掛けた

**Q9.** H<sup>+</sup> = 0.20×0.100 = 0.020 mol、OH<sup>−</sup> = 0.10×0.150 = 0.015 mol → 残る H<sup>+</sup> = 0.0050 mol。体積は合計 250 mL = 0.250 L なので 0.0050 ÷ 0.250 = 0.020 mol/L。

ひっかけ: (a) 体積を合計していない / (b) 足し引きの逆 / (c) 物質量のまま答えた

## ここを押さえる

- 中和の量は H<sup>+</sup> と OH<sup>−</sup> の数だけで決まる。電離度・強弱は関係しない。
- 混合溶液の濃度は「余った mol ÷ 合計の体積」。
