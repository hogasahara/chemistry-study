# 確認ドリル #6 — 指示薬と中和

分野: 酸と塩基 ・ 出典: プリント 酸塩基5〜6 ・ 目安 12分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 指示薬 | 水溶液の pH によって色が変化する試薬 |
| 変色域 | 指示薬の色が変化する pH の範囲 |
| フェノールフタレイン(PP) | 変色域 pH 8.0〜9.8。無色 → 赤(塩基性側で変色) |
| メチルオレンジ(MO) | 変色域 pH 3.1〜4.4。赤 → 黄(酸性側で変色) |
| 中和 | 酸の H<sup>+</sup> と塩基の OH<sup>−</sup> から水ができ、互いの性質を打ち消し合う反応 |
| 塩(えん) | 酸の陰イオンと塩基の陽イオンがイオン結合した物質 |
| HCl + NH<sub>3</sub> → NH<sub>4</sub>Cl | 水を生じない中和(塩のみができる) |

## 設問

所要時間を測ってから始める。

**Q1.** メチルオレンジの変色域は pH 3.1〜4.4 で、それより酸性側では赤色を示す。

正 / 誤

**Q2.** 【組み合わせ】 pH 6 の水溶液に、フェノールフタレインとメチルオレンジをそれぞれ加えたときの色の組み合わせとして正しいものはどれか。

- (a) PP 赤 ・ MO 黄
- (b) PP 無色 ・ MO 黄
- (c) PP 無色 ・ MO 赤

**Q3.** 酸・塩基が強いか弱いかによって、完全に中和するのに必要な相手の量が変わる。

正 / 誤

**Q4.** 【計算】 酢酸分子が 200 個ある。電離度は 0.020 とする。この酢酸を完全に中和するのに必要な水酸化ナトリウムの粒子の数はいくらか。

- (a) 4 個
