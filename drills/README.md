# 確認ドリルのやり方(紙でやる場合)

各ドリルは1フォルダ = 1回分(10〜15分)。フォルダ内の紙版は次の2つ。

- `question.md` — 用語チェック+設問(答えを見ずにここまでやる)
- `answers.md` — 解答・解説・ミスの種類(答え合わせ用)

## 手順

1. **用語チェック(2分)**: 冒頭の用語表に目を通す
2. **設問(目安時間を測る)**: ストップウォッチを起動して解く。計算は紙に途中式を書く。プリントは見ない
3. **答え合わせ(3分)**: answers.md で採点。ミスした問題は「ひっかけ」欄で**ミスの種類**を確認
4. **記録(1分)**: サイトの記録ページ(log.html)の手入力フォームに正解数・問題数・所要時間を入れる
5. **仕上げ**: ミスした問題に対応するプリントの箇所を読み直す

## 目安

| 正答率 | 次にやること |
|-------|-------------|
| 〜60% | プリントを読み直してから、同じドリルをもう一度 |
| 60〜80% | ミスした問題だけ解き直し+用語カード |
| 80%〜 | 目安時間内に解けるかを意識する |
