## 解説

**Q1.** どちらも炭素 C だけからなる単体で、性質が異なる → 同素体。定石:「同じ元素の単体どうし」なら同素体、「同じ元素の原子どうし」なら同位体。

**Q2.** 化学式1つで表せるものは純物質。空気は N<sub>2</sub>・O<sub>2</sub> などの混合物。

ひっかけ: (a) 化学式で書ける=純物質 / (b) 化学式で書ける=純物質 / (d) 化学式で書ける=純物質

**Q3.** H<sub>2</sub>O の分子量 = 1.0×2 + 16 = 18。物質量 = 質量 ÷ モル質量 = 9.0 ÷ 18 = 0.50 mol。

ひっかけ: (a) 割り算の逆 / (c) 分子量の誤り / (d) 桁ミス

**Q4.** Cl は電子を1個受け取って1価の陰イオン Cl<sup>−</sup> になる。

ひっかけ: (a) 価数の誤り / (b) 分子とイオンの混同 / (c) 符号の誤り

**Q5.** 同位体は陽子の数が同じで中性子の数が異なる(b は誤)。電子配置が同じなので化学的性質はほぼ同じ(a は正)。

ひっかけ: (a) 定義の誤り / (c) 定義の誤り / (d) 定義の誤り

**Q6.** 同位体は「陽子の数が同じ」原子どうし → A と B(どちらも陽子6 = 炭素)。B と C は質量数が同じ14だが元素が違う。

ひっかけ: (b) 中性子の数で判断 / (c) 質量数で判断 / (d) 定義の誤り

## ここを押さえる

- 同素体は「単体」どうし、同位体は「原子」どうし。
- 物質量 = 質量 ÷ モル質量。答えの桁と単位を最後に必ず確認する。
