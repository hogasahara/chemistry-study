# 確認ドリル #0 — サンプル(動作確認用)

分野: 物質の構成 ・ 出典: サンプルのため出典なし。先生のプリントが届いたら削除する ・ 目安 10分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 同素体 | 同じ元素からなる単体で、性質が異なるもの(例: ダイヤモンドと黒鉛) |
| 同位体 | 原子番号(陽子の数)が同じで、中性子の数が異なる原子どうし |
| 混合物 | 2種類以上の物質が混じり合ったもの(例: 空気、海水) |
| 物質量 | 粒子の数を 6.0×10<sup>23</sup> 個 = 1 mol として表した量 |
| H<sub>2</sub>O | 水 |
| Cl<sup>−</sup> | 塩化物イオン |

## 設問

所要時間を測ってから始める。

**Q1.** ダイヤモンドと黒鉛は、互いに同素体である。

正 / 誤

**Q2.** 【用語】 次のうち、混合物はどれか。

- (a) 水 H<sub>2</sub>O
- (b) 二酸化炭素 CO<sub>2</sub>
- (c) 空気
- (d) 塩化ナトリウム NaCl

**Q3.** 【計算】 水 H<sub>2</sub>O 9.0 g の物質量は何 mol か。原子量は H = 1.0、O = 16 とする。

- (a) 2.0 mol
- (b) 0.50 mol
- (c) 0.56 mol
- (d) 0.050 mol

**Q4.** 【穴埋め】 塩化ナトリウム NaCl は、Na<sup>+</sup> と【 ア 】がイオン結合してできている。アに入るものはどれか。

- (a) Cl<sup>2−</sup>
- (b) Cl<sub>2</sub>
- (c) Cl<sup>+</sup>
- (d) Cl<sup>−</sup>

**Q5.** 【組み合わせ】 同位体についての記述 a・b の正誤の組み合わせとして正しいものはどれか。<br>a 同位体どうしの化学的性質はほぼ同じである。<br>b 同位体どうしは陽子の数が異なる。

- (a) a 正 ・ b 正
- (b) a 正 ・ b 誤
- (c) a 誤 ・ b 正
- (d) a 誤 ・ b 誤

**Q6.** 【グラフ・表】 次の表の原子 A〜C のうち、互いに同位体の関係にあるものはどれか。

| 原子 | 陽子の数 | 中性子の数 |
|---|---|---|
| A | 6 | 6 |
| B | 6 | 8 |
| C | 7 | 7 |

- (a) A と B
- (b) A と C
- (c) B と C
- (d) 該当なし
