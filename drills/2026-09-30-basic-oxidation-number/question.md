# 基礎⑥ 酸化数の基本

分野: 酸化還元(基礎) ・ 出典: 基礎(酸化還元の前提) ・ 目安 5分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 単体の酸化数 | 0(Fe, O<sub>2</sub>, Cl<sub>2</sub> など) |
| 化合物中の H と O | H は +1、O は −2 |
| 化合物の酸化数の合計 | 0 |
| 単原子イオンの酸化数 | イオンの電荷と同じ(Na<sup>+</sup> は +1) |
| 多原子イオンの酸化数の合計 | イオンの電荷と同じ |

## 設問

所要時間を測ってから始める。

**Q1.** 【計算】 鉄 Fe(単体)の Fe の酸化数はいくらか。

- (a) +2
- (b) +3
- (c) 0
- (d) −2

**Q2.** 【計算】 塩化物イオン Cl<sup>−</sup> の Cl の酸化数はいくらか。

- (a) −1
- (b) +1
- (c) 0
- (d) −2

**Q3.** 【計算】 H<sub>2</sub>O の H の酸化数はいくらか。

- (a) −1
- (b) 0
- (c) +2
- (d) +1

**Q4.** 【計算】 CO<sub>2</sub> の C の酸化数はいくらか。

- (a) +2
- (b) +4
- (c) −4
- (d) 0

**Q5.** 【計算】 SO<sub>4</sub><sup>2−</sup> の S の酸化数はいくらか。

- (a) +4
- (b) +8
- (c) +2
- (d) +6

**Q6.** 【計算】 NaCl の Na の酸化数はいくらか。

- (a) +1
- (b) 0
- (c) −1
- (d) +2

**Q7.** 【用語】 ある原子の酸化数が +2 から 0 に変わった。この原子はどうなったか。

- (a) 酸化された
- (b) 還元された
- (c) どちらでもない
- (d) 酸化も還元もされた

**Q8.** 【用語】 「電子を失う」ことを何というか。

- (a) 還元
- (b) 中和
- (c) 酸化
- (d) 電離
