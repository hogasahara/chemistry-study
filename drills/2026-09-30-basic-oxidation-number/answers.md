## 解説

**Q1.** 単体の酸化数は必ず 0。

ひっかけ: (a) イオンと混同 / (b) イオンと混同 / (d) 符号の誤り

**Q2.** 単原子イオンは電荷と同じ → −1。

ひっかけ: (b) 符号の誤り / (c) 単体と混同 / (d) 計算の誤り

**Q3.** 化合物中の H は +1(1個あたり)。2個あっても1個分で答える。

ひっかけ: (a) 例外と混同 / (b) 単体と混同 / (c) 個数を掛けた

**Q4.** x + (−2)×2 = 0 → x = +4。

ひっかけ: (a) O の個数の見落とし / (c) 符号の誤り / (d) 単体と混同

**Q5.** x + (−2)×4 = −2 → x = +6。

ひっかけ: (a) 計算の誤り / (b) イオンの電荷を無視 / (c) 計算の誤り

**Q6.** アルカリ金属(Na)は化合物中で +1。Cl は −1 で合計 0。

ひっかけ: (b) 単体と混同 / (c) 符号の誤り / (d) 2族と混同

**Q7.** 酸化数が減った → 還元された(電子を受け取った)。

ひっかけ: (a) 増減と酸化・還元の対応の誤り / (c) 定義の誤り / (d) 定義の誤り

**Q8.** 電子を失う = 酸化(酸化数が増える)。電子を受け取る = 還元。

ひっかけ: (a) 酸化と還元の取り違え / (b) 用語の誤り / (d) 用語の誤り

## ここを押さえる

- 酸化数は「H +1・O −2・合計 0(イオンは電荷)」で x を解く。
- 酸化数↑ = 酸化された、↓ = 還元された。
