# 基礎⑤ 滴定の器具と指示薬

分野: 酸と塩基(基礎) ・ 出典: 基礎(中和滴定の前提) ・ 目安 5分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| ビュレット | 滴下した体積を読む |
| ホールピペット | 一定体積を正確にはかりとる |
| メスフラスコ | 正確な濃度の溶液をつくる |
| コニカルビーカー | 酸と塩基を反応させる |
| BTB | 酸性 黄・中性 緑・塩基性 青 |
| 中和点 | 酸と塩基が過不足なく反応した点(中性とは限らない) |

## 設問

所要時間を測ってから始める。

**Q1.** 【用語】 滴下した溶液の体積を読むための器具はどれか。

- (a) ホールピペット
- (b) ビュレット
- (c) メスフラスコ
- (d) コニカルビーカー

**Q2.** 【用語】 正確な濃度の水溶液をつくるための器具はどれか。

- (a) ビュレット
- (b) ホールピペット
- (c) メスフラスコ
- (d) コニカルビーカー

**Q3.** 【用語】 フェノールフタレインは、塩基性の水溶液中で何色か。

- (a) 無色
- (b) 黄色
- (c) 赤色
- (d) 青色

**Q4.** 【用語】 メチルオレンジは、酸性(pH 3 以下)の水溶液中で何色か。

- (a) 赤色
- (b) 黄色
- (c) 無色
- (d) 青色

**Q5.** 【用語】 BTB 溶液は、塩基性の水溶液中で何色か。

- (a) 黄色
- (b) 緑色
- (c) 青色
- (d) 赤色

**Q6.** 【用語】 中和滴定の「中和点」とはどのような点か。

- (a) pH が 7 になる点
- (b) 酸と塩基が過不足なく反応した点
- (c) 指示薬の色が変わり始める点
- (d) 塩基を加え始めた点

**Q7.** 中和点の水溶液は、必ず中性(pH 7)になる。

正 / 誤

**Q8.** 【用語】 使う前に共洗いをしなくてよい器具はどれか。

- (a) ホールピペット
- (b) ビュレット
- (c) 両方とも共洗いが必要
- (d) コニカルビーカー
