## 解説

**Q1.** ビュレット = 目盛りつきの細長い管。コックで少しずつ滴下し、使った体積を読む。

ひっかけ: (a) 器具の役割の取り違え / (c) 器具の役割の取り違え / (d) 器具の役割の取り違え

**Q2.** メスフラスコ = 標線まで水を入れて、決まった体積の溶液をつくる。

ひっかけ: (a) 器具の役割の取り違え / (b) 器具の役割の取り違え / (d) 器具の役割の取り違え

**Q3.** フェノールフタレイン: 酸性〜中性で無色、塩基性(pH 約8以上)で赤色。

ひっかけ: (a) 酸性側の色と混同 / (b) メチルオレンジと混同 / (d) BTB と混同

**Q4.** メチルオレンジ: pH 3.1 以下で赤、4.4 以上で黄。

ひっかけ: (b) 塩基性側の色と混同 / (c) フェノールフタレインと混同 / (d) BTB と混同

**Q5.** BTB: 酸性 黄 → 中性 緑 → 塩基性 青。

ひっかけ: (a) 酸性の色と混同 / (b) 中性の色と混同 / (d) 指示薬の混同

**Q6.** 中和点 = H<sup>+</sup> と OH<sup>−</sup> がちょうど同じ量になった点。できた塩によって酸性・塩基性のこともある。

ひっかけ: (a) 中和点 = 中性と誤解 / (c) 中和点の意味の誤り / (d) 中和点の意味の誤り

**Q7.** 酢酸 + NaOH の中和点は塩基性、アンモニア + HCl の中和点は酸性。中性になるのは強酸 + 強塩基のとき。

**Q8.** コニカルビーカーは水でぬれていても、入れた溶質の物質量は変わらないのでそのまま使える。

ひっかけ: (a) 共洗いの対象の誤り / (b) 共洗いの対象の誤り / (c) 共洗いの対象の誤り

## ここを押さえる

- 器具4つの役割: 読む(ビュレット)・はかりとる(ホールピペット)・つくる(メスフラスコ)・反応させる(コニカルビーカー)。
- 指示薬の色: PP 無色→赤、MO 赤→黄、BTB 黄→緑→青。
