# 確認ドリル #4 — 中和の量的関係と滴定の操作

分野: 酸と塩基 ・ 出典: プリント 酸塩基12〜13 ・ 目安 15分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 中和の量的関係 | 酸の mol × 価数 = 塩基の mol × 価数(H<sup>+</sup> の mol = OH<sup>−</sup> の mol) |
| C×(V/1000)×a = C'×(V'/1000)×b | 濃度 C・価数 a の酸 V mL と、濃度 C'・価数 b の塩基 V' mL がちょうど中和 |
| ホールピペット | 一定体積の溶液を正確にはかりとる器具 |
| ビュレット | 溶液を滴下し、その体積を読む器具 |
| メスフラスコ | 正確な濃度の水溶液をつくる器具 |
| コニカルビーカー | 酸と塩基を反応させる容器(純水でぬれたまま使ってよい) |
| 共洗い | これから使う溶液で器具の内壁を洗う操作(ホールピペット・ビュレットで行う) |

## 設問

所要時間を測ってから始める。

**Q1.** 中和がちょうど完了したとき、酸から生じる H<sup>+</sup> の物質量と、塩基から生じる OH<sup>−</sup> の物質量は等しい。

正 / 誤

**Q2.** 弱酸は電離度が小さいので、同じ濃度・同じ体積の強酸にくらべて、中和に必要な NaOH の量が少ない。

正 / 誤

**Q3.** 【計算】 濃度不明の NaOH 水溶液 20.0 mL を中和するのに、0.25 mol/L の硫酸が 12.0 mL 必要だった。NaOH 水溶液のモル濃度は何 mol/L か。

- (a) 0.15 mol/L
- (b) 0.30 mol/L
- (c) 0.075 mol/L
- (d) 3.0 mol/L

**Q4.** 【計算】 0.10 mol/L のシュウ酸(2価の弱酸)水溶液 10.0 mL を中和するのに必要な 0.050 mol/L の NaOH 水溶液は何 mL か。ただし、シュウ酸の電離度を 0.40 とする。

- (a) 16 mL
- (b) 20 mL
- (c) 4.0 mL
- (d) 40 mL

**Q5.** 【計算】 pH が 3.0 の酢酸水溶液 20 mL を過不足なく中和するのに、0.10 mol/L の NaOH 水溶液は何 mL 必要か。ただし、酢酸の電離度を 0.020 とする。

- (a) 0.20 mL
- (b) 10 mL
- (c) 5.0 mL
- (d) 20 mL

**Q6.** 【用語】 濃度がわからない酸の水溶液を、一定体積だけ正確にはかりとってコニカルビーカーに入れるときに使う器具はどれか。

- (a) ビュレット
- (b) メスフラスコ
- (c) ホールピペット
- (d) メスシリンダー

**Q7.** 【用語】 使う前に「共洗い」をする必要がある器具の組み合わせはどれか。

- (a) ホールピペットとビュレット
- (b) コニカルビーカーとメスフラスコ
- (c) ホールピペットとメスフラスコ
- (d) ビュレットとコニカルビーカー

**Q8.** ビュレットは、内部を早く乾かすために加熱乾燥してから使う。

正 / 誤

**Q9.** 【組み合わせ】 中和滴定の器具についての記述 a・b の正誤の組み合わせとして正しいものはどれか。<br>a コニカルビーカーは純水でぬれたまま使ってよい。<br>b メスフラスコは、これから入れる溶液で共洗いしてから使う。

- (a) a 正 ・ b 正
- (b) a 正 ・ b 誤
- (c) a 誤 ・ b 正
- (d) a 誤 ・ b 誤
