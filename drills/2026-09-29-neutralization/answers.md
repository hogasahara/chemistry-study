## 解説

**Q1.** H<sup>+</sup> + OH<sup>−</sup> → H<sub>2</sub>O は 1 : 1。これが「酸の mol × 価数 = 塩基の mol × 価数」の意味。

**Q2.** 中和が進むと弱酸も次々に電離するので、最終的には価数の分だけすべて中和される。中和の量に電離度は関係しない。

**Q3.** 0.25×(12.0/1000)×2 = C×(20.0/1000)×1 → C = 0.30 mol/L。硫酸は2価。

ひっかけ: (a) 価数の誤り / (c) 価数を反対側に掛けた / (d) 桁ミス

**Q4.** 0.10×(10.0/1000)×2 = 0.050×(V/1000)×1 → V = 40 mL。電離度 0.40 は中和の量に関係しない(ひっかけ)。

ひっかけ: (a) 電離度を掛けた / (b) 価数の誤り / (c) 桁ミス

**Q5.** pH 3.0 → [H<sup>+</sup>] = 1.0×10<sup>−3</sup> mol/L = C × 0.020 → 酢酸の濃度 C = 0.050 mol/L。0.050×20 = 0.10×V → V = 10 mL。ここでは電離度は「濃度を求める」ためだけに使う。

ひっかけ: (a) 電離している分だけで計算 / (c) 価数の誤り / (d) 濃度の求め方の誤り

**Q6.** 一定体積を正確にはかりとる → ホールピペット。ビュレットは滴下量を読む、メスフラスコは正確な濃度の溶液をつくる。

ひっかけ: (a) 器具の役割の取り違え / (b) 器具の役割の取り違え / (d) 精度の低い器具を選んだ

**Q7.** ホールピペット・ビュレットは中の溶液の濃度が薄まると困るので共洗いする。コニカルビーカー・メスフラスコは、水でぬれていても入れる溶質の物質量は変わらないのでそのまま使える。

ひっかけ: (b) 共洗いの対象の誤り / (c) 共洗いの対象の誤り / (d) 共洗いの対象の誤り

**Q8.** 正確な目盛りのある器具(ホールピペット・ビュレット・メスフラスコ)は、ガラスが変形して目盛りが狂うので加熱乾燥しない。

**Q9.** a: 正(溶質の物質量は変わらない)。b: 誤(メスフラスコは最後に純水で標線まで薄めるので、純水でぬれていてよい。共洗いすると溶質が増えてしまう)。

ひっかけ: (a) 共洗いの対象の誤り / (c) 共洗いの対象の誤り / (d) 共洗いの対象の誤り

## ここを押さえる

- C×(V/1000)×a = C'×(V'/1000)×b。価数を掛けるのを忘れない。電離度は中和の量に関係しない。
- 共洗いするのは「中の溶液の濃度が変わると困る」ホールピペットとビュレットだけ。
