# 基礎④ 中和と塩の基本

分野: 酸と塩基(基礎) ・ 出典: 基礎(中和・塩の前提) ・ 目安 5分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 中和 | 酸 + 塩基 → 塩 + 水 |
| 強酸 | HCl, HNO<sub>3</sub>, H<sub>2</sub>SO<sub>4</sub> |
| 弱酸 | CH<sub>3</sub>COOH, H<sub>2</sub>CO<sub>3</sub>, H<sub>2</sub>S, (COOH)<sub>2</sub>, H<sub>3</sub>PO<sub>4</sub> |
| 強塩基 | NaOH, KOH, Ca(OH)<sub>2</sub>, Ba(OH)<sub>2</sub> |
| 弱塩基 | NH<sub>3</sub>, Cu(OH)<sub>2</sub>, Fe(OH)<sub>3</sub> など |
| 塩の液性 | もとの酸・塩基の強い方の性質 |

## 設問

所要時間を測ってから始める。

**Q1.** 【用語】 硝酸と水酸化カリウムの中和でできる塩はどれか。

- (a) KNO<sub>3</sub>
- (b) KOH
- (c) HNO<sub>3</sub>
- (d) K<sub>2</sub>NO<sub>3</sub>

**Q2.** 【反応式】 2HCl + Ca(OH)<sub>2</sub> → CaCl<sub>2</sub> + 【 ア 】H<sub>2</sub>O のアに入る係数はどれか。

- (a) 1
- (b) 2
- (c) 3
- (d) 4

**Q3.** 【用語】 次のうち、強酸はどれか。

- (a) CH<sub>3</sub>COOH
- (b) H<sub>2</sub>CO<sub>3</sub>
- (c) HNO<sub>3</sub>
- (d) H<sub>2</sub>S

**Q4.** 【用語】 次のうち、強塩基はどれか。

- (a) NH<sub>3</sub>
- (b) Cu(OH)<sub>2</sub>
- (c) Fe(OH)<sub>3</sub>
- (d) KOH

**Q5.** 【計算】 硫酸 1 mol をちょうど中和するのに必要な NaOH は何 mol か。

- (a) 1 mol
- (b) 2 mol
- (c) 0.5 mol
- (d) 4 mol

**Q6.** 【用語】 塩化アンモニウム NH<sub>4</sub>Cl は、どの酸とどの塩基の中和でできる塩か。

- (a) HCl と NH<sub>3</sub>
- (b) HCl と NaOH
- (c) H<sub>2</sub>SO<sub>4</sub> と NH<sub>3</sub>
- (d) HNO<sub>3</sub> と NH<sub>3</sub>

**Q7.** 【用語】 炭酸カリウム K<sub>2</sub>CO<sub>3</sub> の水溶液の液性はどれか。

- (a) 酸性
- (b) 中性
- (c) 塩基性
- (d) 判断できない

**Q8.** 中和に必要な量は、酸・塩基の強弱に関係なく、物質量と価数で決まる。

正 / 誤
