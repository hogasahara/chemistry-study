## 解説

**Q1.** 電子を失う物質があれば、必ずその電子を受け取る物質がある(同時性)。

**Q2.** Fe<sub>2</sub>O<sub>3</sub> は酸素を失って Fe になった → 還元された。酸素を受け取った CO は酸化された。

ひっかけ: (a) 酸素の授受の向きの誤り / (c) 定義の誤り / (d) 定義の誤り

**Q3.** H<sub>2</sub>S は水素を失って S になった → 酸化された。水素を受け取った Cl<sub>2</sub> は還元された。

ひっかけ: (b) 水素の授受の向きの誤り / (c) 定義の誤り / (d) 定義の誤り

**Q4.** 還元 = 電子を受け取る(酸化数が減る)。酸化 = 電子を失う(酸化数が増える)。

ひっかけ: (a) 酸化と還元の取り違え / (b) 酸化と還元の取り違え / (c) 酸化と還元の取り違え

**Q5.** (+1)×2 + x + (−2)×3 = 0 → x = +4。

ひっかけ: (a) 計算の誤り / (c) 硫酸 H<sub>2</sub>SO<sub>4</sub> と混同 / (d) 符号の誤り

**Q6.** 多原子イオンは総和が電荷に等しい: x + (−2)×2 = −1 → x = +3。

ひっかけ: (b) NO<sub>3</sub><sup>−</sup> と混同 / (c) イオンの電荷を無視 / (d) 符号の誤り

**Q7.** Na は +1(アルカリ金属)。(+1)×2 + 2x = 0 → x = −1。過酸化物の O は −1 になる例外。

ひっかけ: (a) 例外の見落とし / (c) 計算の誤り / (d) 符号の誤り

**Q8.** Li はアルカリ金属で +1 → H は −1。金属(陽性元素)と H の化合物では H が −1 になる例外。

ひっかけ: (a) 計算の誤り / (b) 例外の見落とし / (c) 計算の誤り

**Q9.** 2x + (−2)×7 = −2 → 2x = +12 → x = +6。Cr が2個あるので最後に 2 で割る。

ひっかけ: (a) イオンの電荷を無視 / (b) 原子の数で割り忘れ / (d) 計算の誤り

**Q10.** a: 単体はどんな形でも 0(正)。b: Mg は2族なので +2(誤)。Cl が −1 ×2 = −2 とも合う。

ひっかけ: (a) 2族の酸化数の誤り / (c) 単体の酸化数の誤り / (d) 単体の酸化数の誤り

## ここを押さえる

- 酸化 = O をもらう・H を失う・e<sup>−</sup> を失う(酸化数↑)。還元はその逆。
- 酸化数は「H +1、O −2、総和 0(イオンなら電荷)」で x を解く。例外は過酸化物の O と金属水素化物の H。
