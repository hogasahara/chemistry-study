# 確認ドリル #10 — 酸化と還元・酸化数のルール

分野: 酸化還元 ・ 出典: プリント 酸化還元1〜2 ・ 目安 12分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 酸化 | 酸素を受け取る / 水素を失う / 電子を失う |
| 還元 | 酸素を失う / 水素を受け取る / 電子を受け取る |
| 酸化還元の同時性 | 酸化反応と還元反応は必ず同時に起こる |
| 酸化数 | 1個の原子の酸化の程度を表す数値。大きいほど酸化された度合いが大きい |
| 酸化数のルール①② | 単体は 0。化合物中の H は +1、O は −2 で、総和は 0 |
| 酸化数のルール③④ | 単原子イオンは電荷と同じ。多原子イオンは総和が電荷と同じ |
| 酸化数のルール⑤ | 化合物中のアルカリ金属は +1、2族元素は +2 |
| 酸化数の例外 | 過酸化物(H<sub>2</sub>O<sub>2</sub> など)の O は −1、金属の水素化合物(NaH など)の H は −1 |

**Q2.** 【用語】 Fe<sub>2</sub>O<sub>3</sub> + 3CO → 2Fe + 3CO<sub>2</sub> の反応で、Fe<sub>2</sub>O<sub>3</sub> はどうなったか。

- (a) 酸化された
- (b) 還元された
- (c) どちらでもない
- (d) 酸化も還元もされた

**Q4.** 【用語】 電子のやりとりで考えたとき、「還元された」の説明として正しいものはどれか。

- (b) a 正 ・ b 誤
