## 解説

**Q1.** H<sub>2</sub> : O<sub>2</sub> = 2 : 1 → 4.0 × 1/2 = 2.0 mol。

ひっかけ: (b) 係数の比の無視 / (c) 係数の比の逆 / (d) 計算の誤り

**Q2.** CH<sub>4</sub> = 16 → 8.0 ÷ 16 = 0.50 mol。H<sub>2</sub>O は ×2 で 1.0 mol → 18 g。

ひっかけ: (a) 係数の比の無視 / (c) 係数の誤り / (d) 質量のまま答えた

**Q3.** CH<sub>4</sub> : CO<sub>2</sub> = 1 : 1 → CO<sub>2</sub> 0.50 mol → 0.50 × 22.4 = 11.2 L。

ひっかけ: (b) 係数の誤り / (c) mol のまま答えた / (d) 計算の誤り

**Q4.** 6.5 ÷ 65 = 0.10 mol。Zn : H<sub>2</sub> = 1 : 1 → 0.10 × 22.4 = 2.24 L。

ひっかけ: (a) HCl の係数を使った / (b) mol のまま答えた / (c) g に直接 22.4 を掛けた

**Q5.** HCl : NaOH = 1 : 1 → 0.10 mol × 40 = 4.0 g。

ひっかけ: (a) 1 mol 分で答えた / (b) 桁ミス / (d) 割り算の逆

**Q6.** 4.9 ÷ 98 = 0.050 mol。H<sub>2</sub>SO<sub>4</sub> + 2NaOH → Na<sub>2</sub>SO<sub>4</sub> + 2H<sub>2</sub>O より NaOH は ×2 で 0.10 mol。

ひっかけ: (b) 価数(係数)の誤り / (c) 計算の誤り / (d) 質量のまま答えた

**Q7.** 10 ÷ 100 = 0.10 mol → CO<sub>2</sub> も 0.10 mol → 0.10 × 44 = 4.4 g。

ひっかけ: (b) HCl の係数を使った / (c) 質量のまま答えた / (d) 体積と混同

**Q8.** H<sub>2</sub> : NH<sub>3</sub> = 3 : 2 → 6.0 × 2/3 = 4.0 mol。

ひっかけ: (a) 係数の比の逆 / (b) 係数の比の無視 / (d) 割らずに掛けた

**Q9.** 係数の比は物質量(mol)の比。質量の比ではないので、必ず mol に直してから比を使う。

## ここを押さえる

- 反応の計算は「mol に直す → 係数の比 → 単位を戻す」の3ステップ。
- 中和も同じ: 化学反応式の係数(= 価数)で mol をそろえる。
