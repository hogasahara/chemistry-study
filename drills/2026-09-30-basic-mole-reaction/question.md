# 基礎⑨ 化学反応式と物質量

分野: 物質量(基礎) ・ 出典: 基礎(mol の土台。中和の計算の前提) ・ 目安 7分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 係数の比 | 反応する物質の物質量の比(同温・同圧の気体なら体積の比) |
| 2H<sub>2</sub> + O<sub>2</sub> → 2H<sub>2</sub>O | H<sub>2</sub> : O<sub>2</sub> : H<sub>2</sub>O = 2 : 1 : 2(mol) |
| 質量保存の法則 | 反応の前後で物質の質量の総和は変わらない |
| 量的関係の解き方 | g・L・個数 → mol に直す → 係数の比 → 求めたい単位に直す |

## 設問

所要時間を測ってから始める。

**Q1.** 【用語】 2H<sub>2</sub> + O<sub>2</sub> → 2H<sub>2</sub>O で、H<sub>2</sub> 4.0 mol と過不足なく反応する O<sub>2</sub> は何 mol か。

- (a) 2.0 mol
- (b) 4.0 mol
- (c) 8.0 mol
- (d) 1.0 mol

**Q2.** 【計算】 メタンの燃焼 CH<sub>4</sub> + 2O<sub>2</sub> → CO<sub>2</sub> + 2H<sub>2</sub>O で、CH<sub>4</sub> 8.0 g が完全に燃焼すると、H<sub>2</sub>O は何 g できるか。原子量は H = 1.0、C = 12、O = 16 とする。

- (a) 9.0 g
- (b) 18 g
- (c) 36 g
- (d) 8.0 g

**Q3.** 【計算】 CH<sub>4</sub> 0.50 mol が完全に燃焼したとき、発生する CO<sub>2</sub> は標準状態で何 L か。

- (a) 11.2 L
- (b) 22.4 L
- (c) 0.50 L
- (d) 5.6 L

**Q4.** 【計算】 Zn + 2HCl → ZnCl<sub>2</sub> + H<sub>2</sub> で、亜鉛 6.5 g がすべて反応すると、H<sub>2</sub> は標準状態で何 L 発生するか。Zn = 65 とする。

- (a) 4.48 L
- (b) 0.10 L
- (c) 146 L
- (d) 2.24 L

**Q5.** 【計算】 塩化水素 0.10 mol をちょうど中和するのに必要な NaOH は何 g か。NaOH = 40 とする。

- (a) 40 g
- (b) 0.40 g
- (c) 4.0 g
- (d) 2.5×10<sup>−3</sup> g

**Q6.** 【計算】 硫酸 H<sub>2</sub>SO<sub>4</sub> 4.9 g をちょうど中和するのに必要な NaOH は何 mol か。H<sub>2</sub>SO<sub>4</sub> = 98 とする。

- (a) 0.10 mol
- (b) 0.050 mol
- (c) 0.20 mol
- (d) 4.9 mol

**Q7.** 【計算】 CaCO<sub>3</sub> + 2HCl → CaCl<sub>2</sub> + H<sub>2</sub>O + CO<sub>2</sub> で、CaCO<sub>3</sub> 10 g に十分な量の塩酸を加えた。発生する CO<sub>2</sub> は何 g か。CaCO<sub>3</sub> = 100、CO<sub>2</sub> = 44 とする。

- (a) 4.4 g
- (b) 8.8 g
- (c) 10 g
- (d) 2.24 g

**Q8.** 【用語】 N<sub>2</sub> + 3H<sub>2</sub> → 2NH<sub>3</sub> で、H<sub>2</sub> 6.0 mol がすべて反応すると NH<sub>3</sub> は何 mol できるか。

- (a) 2.0 mol
- (b) 6.0 mol
- (c) 4.0 mol
- (d) 18 mol
