# 基礎① 酸・塩基の化学式とイオン

分野: 酸と塩基(基礎) ・ 出典: 基礎(全プリントの前提) ・ 目安 5分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| HCl | 塩化水素(水溶液は塩酸)。1価の強酸 |
| HNO<sub>3</sub> | 硝酸。1価の強酸 |
| H<sub>2</sub>SO<sub>4</sub> | 硫酸。2価の強酸 |
| CH<sub>3</sub>COOH | 酢酸。1価の弱酸 |
| H<sub>3</sub>PO<sub>4</sub> | リン酸。3価の弱酸 |
| NaOH | 水酸化ナトリウム。1価の強塩基 |
| Ca(OH)<sub>2</sub> | 水酸化カルシウム。2価の強塩基 |
| NH<sub>3</sub> | アンモニア。1価の弱塩基 |
| SO<sub>4</sub><sup>2−</sup> | 硫酸イオン |
| NH<sub>4</sub><sup>+</sup> | アンモニウムイオン |
| OH<sup>−</sup> | 水酸化物イオン |
| CO<sub>3</sub><sup>2−</sup> | 炭酸イオン |

## 設問

所要時間を測ってから始める。

**Q1.** 【用語】 硝酸の化学式はどれか。

- (a) HNO<sub>2</sub>
- (b) HNO<sub>3</sub>
- (c) H<sub>2</sub>NO<sub>3</sub>
- (d) NH<sub>3</sub>

**Q2.** 【用語】 CH<sub>3</sub>COOH の名前はどれか。

- (a) 酢酸
- (b) 炭酸
- (c) シュウ酸
- (d) 硫酸

**Q3.** 【用語】 硫酸イオンのイオン式はどれか。

- (a) SO<sub>4</sub><sup>−</sup>
- (b) SO<sub>3</sub><sup>2−</sup>
- (c) SO<sub>4</sub><sup>2−</sup>
- (d) S<sup>2−</sup>

**Q4.** 【用語】 NH<sub>4</sub><sup>+</sup> の名前はどれか。

- (a) アンモニア
- (b) アンモニウムイオン
- (c) 硝酸イオン
- (d) 水酸化物イオン

**Q5.** 【用語】 水酸化カルシウムの化学式はどれか。

- (a) CaO
- (b) CaOH
- (c) CaCO<sub>3</sub>
- (d) Ca(OH)<sub>2</sub>

**Q6.** 【穴埋め】 硫酸の電離: H<sub>2</sub>SO<sub>4</sub> → 2H<sup>+</sup> + 【 ア 】 のアに入るものはどれか。

- (a) SO<sub>4</sub><sup>−</sup>
- (b) SO<sub>4</sub><sup>2−</sup>
- (c) 2SO<sub>4</sub><sup>−</sup>
- (d) H<sub>2</sub>SO<sub>4</sub>

**Q7.** 【用語】 リン酸 H<sub>3</sub>PO<sub>4</sub> の価数はいくつか。

- (a) 1
- (b) 2
- (c) 3
- (d) 4

**Q8.** 【用語】 酢酸 CH<sub>3</sub>COOH の価数はいくつか。

- (a) 1
- (b) 2
- (c) 3
- (d) 4

**Q9.** 【用語】 水酸化バリウム Ba(OH)<sub>2</sub> の価数はいくつか。

- (a) 1
- (b) 3
- (c) 2
- (d) 4

**Q10.** アンモニア NH<sub>3</sub> は OH を持たないが、水溶液中で OH<sup>−</sup> を生じるので塩基である。

正 / 誤
