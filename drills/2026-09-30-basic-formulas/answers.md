## 解説

**Q1.** 硝酸 = HNO<sub>3</sub>。NH<sub>3</sub> はアンモニア。

ひっかけ: (a) 似た化学式と混同 / (c) 化学式の誤り / (d) 名前の似た物質と混同

**Q2.** CH<sub>3</sub>COOH = 酢酸(お酢の成分)。炭酸は H<sub>2</sub>CO<sub>3</sub>、シュウ酸は (COOH)<sub>2</sub>。

ひっかけ: (b) 名前の誤り / (c) 名前の誤り / (d) 名前の誤り

**Q3.** H<sub>2</sub>SO<sub>4</sub> から H<sup>+</sup> が2個とれるので、残りは 2− の SO<sub>4</sub><sup>2−</sup>。

ひっかけ: (a) 電荷の誤り / (b) 化学式の誤り / (d) 化学式の誤り

**Q4.** NH<sub>3</sub>(アンモニア)が H<sup>+</sup> を受け取ると NH<sub>4</sub><sup>+</sup>(アンモニウムイオン)。

ひっかけ: (a) 分子とイオンの混同 / (c) 名前の誤り / (d) 名前の誤り

**Q5.** Ca は Ca<sup>2+</sup> なので OH<sup>−</sup> が2つ必要 → Ca(OH)<sub>2</sub>。

ひっかけ: (a) 酸化物と混同 / (b) 電荷の数え忘れ / (c) 炭酸塩と混同

**Q6.** 左右で電荷の合計が 0 になる: (+1)×2 + (−2) = 0。

ひっかけ: (a) 電荷の誤り / (c) 電荷の誤り / (d) 電離の理解の誤り

**Q7.** H<sup>+</sup> になれる H が3つ → 3価。

ひっかけ: (a) 価数の誤り / (b) 価数の誤り / (d) O の数と混同

**Q8.** H は4つあるが、H<sup>+</sup> になれるのは COOH の H だけ → 1価。

ひっかけ: (b) 価数の誤り / (c) 価数の誤り / (d) H の数で価数を数えた

**Q9.** OH<sup>−</sup> を2つ出せる → 2価の塩基。

ひっかけ: (a) 価数の誤り / (b) 価数の誤り / (d) 価数の誤り

**Q10.** NH<sub>3</sub> + H<sub>2</sub>O ⇄ NH<sub>4</sub><sup>+</sup> + OH<sup>−</sup>。水から H<sup>+</sup> を受け取って OH<sup>−</sup> を生じる。

## ここを押さえる

- 酸は「H<sup>+</sup> になれる H の数」、塩基は「OH<sup>−</sup> の数」が価数。酢酸は1価。
- イオン式は電荷まで書く(SO<sub>4</sub><sup>2−</sup>、NH<sub>4</sub><sup>+</sup>)。
