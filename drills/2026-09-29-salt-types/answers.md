## 解説

**Q1.** 「酸性塩」は組成式に酸の H が残っているという分類名。NaHCO<sub>3</sub> は酸性塩だが水溶液は塩基性。

**Q2.** KHSO<sub>4</sub> には硫酸の H が残っている。NH<sub>4</sub>Cl の H は NH<sub>4</sub><sup>+</sup>(塩基側)の一部で、酸の H ではない → 正塩。

ひっかけ: (a) NH<sub>4</sub><sup>+</sup> の H を酸の H と誤解 / (c) 塩基性塩との混同 / (d) 正塩との混同

**Q3.** MgCl(OH) には塩基 Mg(OH)<sub>2</sub> の OH が1つ残っている。Na<sub>2</sub>CO<sub>3</sub> は水溶液が塩基性だが、分類は正塩。NaOH は塩ではなく塩基。

ひっかけ: (a) 酸性塩との混同 / (b) 液性で分類した / (d) 塩基と塩の混同

**Q4.** リン酸 H<sub>3</sub>PO<sub>4</sub> の H が1つ残っている(HPO<sub>4</sub><sup>2−</sup>)→ 酸性塩。

ひっかけ: (b) H の見落とし / (c) 塩基性塩との混同 / (d) 塩の定義の誤り

**Q5.** K<sub>2</sub>SO<sub>4</sub> は強酸 H<sub>2</sub>SO<sub>4</sub> + 強塩基 KOH の正塩 → 中性。Na<sub>2</sub>CO<sub>3</sub>・CH<sub>3</sub>COOK は塩基性、NH<sub>4</sub>Cl は酸性。

ひっかけ: (a) 強弱の組み合わせの誤り / (c) 強弱の組み合わせの誤り / (d) 強弱の組み合わせの誤り

**Q6.** CuSO<sub>4</sub> は強酸 H<sub>2</sub>SO<sub>4</sub> + 弱塩基 Cu(OH)<sub>2</sub> の塩 → 酸性。NaHCO<sub>3</sub> は酸性塩だが塩基性。

ひっかけ: (a) 強弱の組み合わせの誤り / (b) 強弱の組み合わせの誤り / (c) 分類名で液性を判断

**Q7.** a: 正(もとの硫酸は強酸なので電離する)。b: 誤(もとの炭酸は弱酸なので HCO<sub>3</sub><sup>−</sup> は電離前の形にもどりやすく、加水分解で OH<sup>−</sup> を生じて塩基性)。

ひっかけ: (a) 分類名で液性を判断 / (c) 電離と加水分解の混同 / (d) 電離と加水分解の混同

**Q8.** NH<sub>4</sub>Cl は強酸 + 弱塩基の塩なので、強い方(酸)の性質 → 酸性。塩基性は誤り。

ひっかけ: (a) 強弱の組み合わせの誤り / (b) 強弱の組み合わせの誤り / (d) 強弱の組み合わせの誤り

**Q9.** HCO<sub>3</sub><sup>−</sup> が水から H<sup>+</sup> を受け取って H<sub>2</sub>CO<sub>3</sub>(弱酸)にもどり、OH<sup>−</sup> が残る → 塩基性。

ひっかけ: (a) 電離と加水分解の混同 / (b) 生成物の誤り / (d) 生成物の誤り

**Q10.** H<sub>2</sub>SO<sub>4</sub> + NaOH → NaHSO<sub>4</sub> + H<sub>2</sub>O。H が1つ残る(酸性塩)。NaOH が 2 mol なら Na<sub>2</sub>SO<sub>4</sub>(正塩)になる。

ひっかけ: (a) 物質量の比の見落とし / (c) 化学式の誤り / (d) 化学式の誤り

## ここを押さえる

- 塩の分類(正塩・酸性塩・塩基性塩)は組成式だけで決まる。液性とは別に考える。
- 液性は「もとの酸・塩基の強い方」。酸性塩は、もとの酸が強酸なら電離して酸性、弱酸なら加水分解して塩基性。
