# 確認ドリル #7 — 塩の種類と水溶液の液性

分野: 酸と塩基 ・ 出典: プリント 酸塩基7〜8 ・ 目安 12分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 正塩 | 組成式中に酸の H も塩基の OH も残っていない塩(Na<sub>2</sub>SO<sub>4</sub>, NaCl, CH<sub>3</sub>COONa, NH<sub>4</sub>Cl) |
| 酸性塩 | 組成式中に酸の H が残っている塩(NaHSO<sub>4</sub>, NaHCO<sub>3</sub>, K<sub>2</sub>HPO<sub>4</sub>) |
| 塩基性塩 | 組成式中に塩基の OH が残っている塩(MgCl(OH), CuCl(OH)) |
| 塩の分類と液性 | 正塩・酸性塩・塩基性塩は組成式による分類で、水溶液の液性とは関係ない |
| 正塩の液性 | もとの酸・塩基の強い方の性質: 強+強 → 中性、弱酸+強塩基 → 塩基性、強酸+弱塩基 → 酸性 |
| NaHSO<sub>4</sub> | 硫酸水素ナトリウム。HSO<sub>4</sub><sup>−</sup> が電離して H<sup>+</sup> を出すので酸性 |
| NaHCO<sub>3</sub> | 炭酸水素ナトリウム。HCO<sub>3</sub><sup>−</sup> が加水分解して OH<sup>−</sup> を出すので塩基性 |

## 設問

所要時間を測ってから始める。

**Q1.** 酸性塩の水溶液は、必ず酸性を示す。

正 / 誤

**Q2.** 【用語】 次のうち、酸性塩はどれか。

- (a) NH<sub>4</sub>Cl
- (b) KHSO<sub>4</sub>
- (c) CaCl(OH)
- (d) K<sub>2</sub>CO<sub>3</sub>

**Q3.** 【用語】 次のうち、塩基性塩はどれか。

- (a) NaHCO<sub>3</sub>
- (b) Na<sub>2</sub>CO<sub>3</sub>
- (c) MgCl(OH)
- (d) NaOH

**Q4.** 【用語】 リン酸水素カルシウム CaHPO<sub>4</sub> は、正塩・酸性塩・塩基性塩のどれに分類されるか。

- (a) 酸性塩
- (b) 正塩
- (c) 塩基性塩
- (d) 塩ではない

**Q5.** 【用語】 次の塩の水溶液のうち、中性を示すものはどれか。

- (a) Na<sub>2</sub>CO<sub>3</sub>
- (b) K<sub>2</sub>SO<sub>4</sub>
- (c) NH<sub>4</sub>Cl
- (d) CH<sub>3</sub>COOK

**Q6.** 【用語】 次の塩の水溶液のうち、酸性を示すものはどれか。

- (a) KNO<sub>3</sub>
- (b) CH<sub>3</sub>COONa
- (c) NaHCO<sub>3</sub>
- (d) CuSO<sub>4</sub>

**Q7.** 【組み合わせ】 酸性塩の水溶液についての記述 a・b の正誤の組み合わせとして正しいものはどれか。<br>a NaHSO<sub>4</sub> の水溶液は、HSO<sub>4</sub><sup>−</sup> が電離して H<sup>+</sup> を生じるので酸性を示す。<br>b NaHCO<sub>3</sub> の水溶液は、酸性塩なので酸性を示す。

- (a) a 正 ・ b 正
- (b) a 正 ・ b 誤
- (c) a 誤 ・ b 正
- (d) a 誤 ・ b 誤

**Q8.** 【グラフ・表】 次の表は、塩ともとの酸・塩基、水溶液の液性をまとめたものである。誤りを含む行はどれか。

|  | 塩 | もとの酸 | もとの塩基 | 液性 |
|---|---|---|---|---|
| ア | NaCl | HCl(強) | NaOH(強) | 中性 |
| イ | CH<sub>3</sub>COONa | CH<sub>3</sub>COOH(弱) | NaOH(強) | 塩基性 |
| ウ | NH<sub>4</sub>Cl | HCl(強) | NH<sub>3</sub>(弱) | 塩基性 |
| エ | KNO<sub>3</sub> | HNO<sub>3</sub>(強) | KOH(強) | 中性 |

- (a) ア
- (b) イ
- (c) ウ
- (d) エ

**Q9.** 【穴埋め】 NaHCO<sub>3</sub> の水溶液では、HCO<sub>3</sub><sup>−</sup> + H<sub>2</sub>O ⇄ H<sub>2</sub>CO<sub>3</sub> + 【 ア 】 の反応(加水分解)が起こる。アに入るものはどれか。

- (a) H<sup>+</sup>
- (b) CO<sub>3</sub><sup>2−</sup>
- (c) OH<sup>−</sup>
- (d) H<sub>2</sub>O

**Q10.** 【反応式】 硫酸 1 mol と水酸化ナトリウム 1 mol を反応させたときにできる塩はどれか。

- (a) Na<sub>2</sub>SO<sub>4</sub>
- (b) NaHSO<sub>4</sub>
- (c) Na<sub>2</sub>SO<sub>3</sub>
- (d) NaSO<sub>4</sub>
