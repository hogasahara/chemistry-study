# 確認ドリル #5 — 中和滴定曲線と指示薬

分野: 酸と塩基 ・ 出典: プリント 酸塩基14 ・ 目安 10分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 中和滴定曲線 | 加えた塩基(酸)の体積と、溶液の pH の関係を表したグラフ |
| pH ジャンプ | 中和点付近で pH が急に大きく変化すること |
| フェノールフタレイン | 変色域が塩基性側(pH 約8〜10)。無色 ⇄ 赤色 |
| メチルオレンジ | 変色域が酸性側(pH 約3〜4.5)。赤色 ⇄ 黄色 |
| 強酸 + 強塩基の滴定 | 中和点は pH 7 付近。フェノールフタレインもメチルオレンジも使える |
| 弱酸 + 強塩基の滴定 | 中和点は塩基性側 → フェノールフタレインのみ |
| 強酸 + 弱塩基の滴定 | 中和点は酸性側 → メチルオレンジのみ |
| 弱酸 + 弱塩基の滴定 | pH ジャンプが見られず、指示薬で中和点を判定できない |

## 設問

所要時間を測ってから始める。

**Q1.** 指示薬は、その変色域が中和点付近の pH ジャンプの範囲内にあれば使用できる。

正 / 誤

**Q2.** 【用語】 酢酸水溶液を NaOH 水溶液で滴定するとき、使える指示薬はどれか。

- (a) メチルオレンジのみ
- (b) フェノールフタレインのみ
- (c) どちらも使える
- (d) どちらも使えない

**Q3.** 【組み合わせ】 アンモニア水を塩酸で滴定するとき、中和点の液性と、使える指示薬の組み合わせとして正しいものはどれか。

- (a) 塩基性 ・ フェノールフタレイン
- (b) 中性 ・ どちらも使える
- (c) 酸性 ・ フェノールフタレイン
- (d) 酸性 ・ メチルオレンジ

**Q4.** 【用語】 酢酸を NaOH で滴定したとき、中和点が塩基性側に寄る理由として正しいものはどれか。

- (a) 中和点では NaOH が余っているから
- (b) 生じた CH<sub>3</sub>COONa が加水分解して OH<sup>−</sup> を生じるから
- (c) 中和点では酢酸が残っているから
- (d) 水の電離が大きくなるから

**Q5.** 【グラフ・表】 4種類の酸の水溶液(いずれも 0.1 mol/L)に、塩基の水溶液を加えていく滴定を行った。次の表のうち、弱酸を強塩基で滴定したものはどれか。

| 滴定 | 滴定前の pH | 中和点の pH | pH ジャンプ |
|---|---|---|---|
| ア | 1 | 約7 | 大きい |
| イ | 3 | 約9 | 塩基性側にある |
| ウ | 1 | 約5 | 酸性側にある |
| エ | 3 | 約7 | ほとんどない |

- (a) ア
- (b) イ
- (c) ウ
- (d) エ

**Q6.** 【組み合わせ】 0.10 mol/L の塩酸 10 mL に 0.10 mol/L の NaOH 水溶液を加えていく滴定について、記述 a・b の正誤の組み合わせとして正しいものはどれか。<br>a 中和点までに加える NaOH 水溶液は 10 mL である。<br>b 中和点の pH は 7 付近で、フェノールフタレインもメチルオレンジも使える。

- (a) a 正 ・ b 正
- (b) a 正 ・ b 誤
- (c) a 誤 ・ b 正
- (d) a 誤 ・ b 誤

**Q7.** 【用語】 弱酸を弱塩基で滴定するとき、指示薬で中和点を判定できない理由として正しいものはどれか。

- (a) 中和反応が起こらないから
- (b) 中和点の pH が必ず 7 ちょうどになるから
- (c) 中和点付近で pH ジャンプがほとんど見られないから
- (d) 塩が生じないから

**Q8.** 【計算】 0.050 mol/L の硫酸 10.0 mL を 0.10 mol/L の NaOH 水溶液で滴定した。中和点までに加える NaOH 水溶液は何 mL か。

- (a) 5.0 mL
- (b) 20 mL
- (c) 10 mL
- (d) 1.0 mL
