# 基礎⑧ 気体の体積と溶液の濃度

分野: 物質量(基礎) ・ 出典: 基礎(mol の土台。プリント範囲の計算の前提) ・ 目安 7分

[解答・解説](answers.md) ・ Web版はトップページから

## 用語チェック(先に目を通す)

| 用語 | 意味 |
|---|---|
| 気体 1 mol の体積 | 標準状態(0℃, 1.013×10<sup>5</sup> Pa)で 22.4 L(気体の種類によらない) |
| 体積 → 物質量 | mol = 体積 [L] ÷ 22.4 L/mol(標準状態) |
| モル濃度 [mol/L] | 溶質の mol ÷ 溶液の体積 [L] |
| 質量パーセント濃度 [%] | 溶質の質量 ÷ 溶液の質量 × 100 |
| 密度 [g/cm<sup>3</sup>] | 1 cm<sup>3</sup>(= 1 mL)あたりの質量 |
| うすめる(希釈) | 溶質の物質量は変わらない |

## 設問

所要時間を測ってから始める。

**Q1.** 【計算】 標準状態で 11.2 L の気体は何 mol か。

- (a) 0.500 mol
- (b) 2.00 mol
- (c) 251 mol
- (d) 11.2 mol

**Q2.** 【計算】 アンモニア 0.25 mol は、標準状態で何 L か。

- (a) 0.011 L
- (b) 89.6 L
- (c) 5.6 L
- (d) 22.4 L

**Q3.** 【計算】 二酸化炭素 4.4 g は、標準状態で何 L か。原子量は C = 12、O = 16 とする。

- (a) 22.4 L
- (b) 2.24 L
- (c) 0.10 L
- (d) 98.6 L

**Q4.** 【計算】 NaOH 2.0 g を水に溶かして 250 mL にした。モル濃度は何 mol/L か。原子量は H = 1.0、O = 16、Na = 23 とする。

- (a) 8.0 mol/L
- (b) 0.050 mol/L
- (c) 2.0×10<sup>−4</sup> mol/L
- (d) 0.20 mol/L

**Q5.** 【計算】 0.10 mol/L の塩化ナトリウム水溶液を 500 mL つくるのに必要な NaCl は何 g か。NaCl = 58.5 とする。

- (a) 2.9 g
- (b) 5.9 g
- (c) 29 g
- (d) 0.050 g

**Q6.** 【計算】 2.0 mol/L の硫酸 10 mL を、水でうすめて 100 mL にした。うすめた後のモル濃度は何 mol/L か。

- (a) 20 mol/L
- (b) 0.20 mol/L
- (c) 0.020 mol/L
- (d) 1.8 mol/L

**Q7.** 【計算】 質量パーセント濃度 20% の NaOH 水溶液(密度 1.2 g/cm<sup>3</sup>)のモル濃度は何 mol/L か。NaOH = 40 とする。

- (a) 5.0 mol/L
- (b) 240 mol/L
- (c) 6.0 mol/L
- (d) 6.0×10<sup>−3</sup> mol/L

**Q8.** 水溶液を水でうすめても、溶けている溶質の物質量は変わらない。
